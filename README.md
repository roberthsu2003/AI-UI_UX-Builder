# AI賦能的UI/UX

在過去，網站專案管理員（Project Manager）往往需要耗費大量時間在跨團隊的溝通與協調上——從繪製原型、撰寫規格書到不斷與設計師和工程師反覆確認細節。如今，透過 AI 技術的賦能，專案管理員能夠快速生成概念草圖、自動化佈局與設計元件，並在極短的時間內進行需求驗證與情境模擬。AI 不僅縮短了耗時的溝通成本，更徹底改變了整個網站開發與 UI/UX 的工作流程，實現了更敏捷、更具視覺化且更有效率的全新協作模式。

## [如何評估現有的網站? >>](./如何評估現有的網站)
> 在進行網站改版與優化前，透過 AI 進行既有網站的健康檢查是至關重要的步驟。本單元引導您如何利用多模態 AI 與 **Gemini in Chrome** 內建工具對現有網站進行快速評估，內容包含：
> * **UI/UX 評估**：包含可用性啟發式評估（尼爾森十大原則）、視覺排版美學、操作動線流暢度。
> * **進階管理指標**：針對 **無障礙規範 (A11y/WCAG/NCC)**、**搜尋引擎優化 (SEO)** 與 **資訊安全 (Security)** 提供代碼/截圖審查提示詞。
> * **實作與工具**：提供長截圖技巧、實用 Prompt 模板，以及適合課堂練習的民間商業網站名單（如台灣高鐵、104人力銀行），協助您快速生成診斷報告並無縫對接原型重構。

## [網站架構觀念 (Website Architecture) >>](./網站架構觀念)
> 作為一名網站專案管理員，理解並掌握網站核心架構知識是不可或缺的。本單元涵蓋網站從立體空間構造、版面佈局、導覽設計、一致性原則到無縫式介面與細節雕琢等六大核心維度，是確保網站專案具備優異易用性與卓越使用者體驗的基石，內容包含：
> * **立體構造與佈局**：涵蓋垂直、水平、前後的立體空間構造，以及單欄、多欄、格狀與回應式網頁（RWD）等佈局模式。
> * **導覽與一致性**：涵蓋全域、區域與麵包屑等導覽列設計原則，以及降低使用者迷路風險的介面一致性規範。
> * **互動與細節**：涵蓋不切換畫面的無縫式介面體驗，以及讓操作更加直覺極簡的設計講究之處。

## [建立提案用的原型網頁：功能導向協作手冊 >>](./建立提案用的原型網頁)
> 本單元以**網站管理者**的視角出發，提供如何與設計師和工程師進行高效溝通的 AI 協作手冊，包含以下核心功能主題：
> * **無設計稿的氛圍與視覺探索**：利用 Google Stitch 逆向導入舊網站並探索新視覺風格與互動故事線。
> * **修改單頁網頁的結構與內容**：利用 Claude Design 進行對話式重構區塊（如單/雙欄調整）與文案微調。
> * **建立全新的網頁頁面**：整合 Stitch、Claude 與 Figma 的全流程 AI 協作，設計符合品牌一致性的新功能頁面。
