# 成為 AI Product Builder：AI 賦能的 UI/UX 實戰

**AI Product Builder** 是 AI 時代興起的新角色：用 AI 把一個想法，從「發現問題」一路帶到「真實使用者能用的產品」。本課程聚焦在 **網站設計** 這條路：過去要做出一個網站原型，得在 PM、設計師與工程師之間來回交接：寫規格書、畫設計稿、切版，每一次交接都是一次誤解的機會。如今 AI 讓「做得出來」變得又快又便宜，真正的瓶頸變成 **「做的是不是對的東西」**。

這門課要帶你成為同時具備 **產品判斷力**、**設計品味** 與 **AI 執行力** 的網站 Builder：先用 AI 診斷既有網站、制定設計規範與創意發想，再用 AI 控制畫布做出原型、找真人做易用性測試，最後把成果部署成任何人都能打開的網址。

> [!NOTE]
> **關於工具資訊**：本課程的觀念（網站架構、使用者需求、易用性測試、設計規範）長期有效；但 AI 工具的介面、方案、額度與模型名稱變動很快。各單元開頭標有「最後更新」月份，若操作畫面與講義不符，請以官方文件為準。

## [AI 設計畫布與 MCP 整合：用 AI 全面控制設計 >>](./AI設計畫布與MCP整合)
> 不用手動拉矩形與像素，全程用 AI 與 MCP 直接控制設計畫布。本單元依 **2026 最新規格** 為四大核心工具各設專章，帶你從 `DESIGN.md` 驅動視覺生成、局部修改與前端轉碼：
> * **Figma × MCP**：免費申請教育方案取得 Full Seat，連接 Claude.ai / ChatGPT / Antigravity 透過 `create_new_file` 與 `use_figma` 讓 AI 寫入變數、元件、修改局部畫框並讀稿轉碼。
> * **pen.dev（Pencil）× MCP**：體驗「Design-in-Code」`.pen` 向量畫布，用 `execute`、`browser`（網頁逆向轉向量）與 `spawn_agents` 多代理平行比稿。
> * **Google Stitch × MCP**：掌握 Live Streaming 即時串流干預、語音控制、`Play` 原型串接，以及透過 `stitch-mcp` 批次生成變體並套用 `DESIGN.md`。
> * **Claude Design**：活用 `claude.ai/design` 與免費版 Artifacts Design 模式，透過自動規範萃取、局部圈選評論與動態滑桿微調設計並交接開發。

## [建立自己的 DESIGN.md：認識設計風格，寫出 AI 看得懂的規範 >>](./建立自己的DESIGN_md)
> 只會說「有質感一點」，AI 就只能產出公版。本單元先用圖解認識常用的設計風格，再把選好的風格寫成 `DESIGN.md`：
> * **認識 DESIGN.md**：上層是給 AI 照抄的設計 Token，下層是給 AI 判斷的設計理由（依 Google 官方開放規格）。
> * **常用設計風格圖鑑**：用同一個示範網頁畫出 10 種風格（極簡、編輯雜誌、現代 SaaS、便當盒、新粗野主義、瑞士格線、玻璃擬態、柔和療癒、暗黑奢華、公共服務），附適合用途與給 AI 的關鍵字。
> * **靈感與比稿、建立與驗證**：從靈感網站判斷風格、請 AI 一次做三種風格比稿，再用「看 → 用 → 抓錯 → 改規範」完成自己的 `DESIGN.md`。

## [Google Stitch 實戰：用說的就能產生 RWD 網站 >>](./Google_Stitch實戰與AI設計畫布)
> 用同一個專案「山城小旅行」走完 Google Stitch 的所有功能，每章附圖解、可直接複製的 Prompt 與親手完成的判斷練習：
> * **入門（01–02）**：認識 Stitch 與 pen.dev 的分工、好 Prompt 的五個部分，以及截圖、草圖、語音等輸入方式。
> * **核心（03–05）**：對話、圈選與變體三種修改方式；主題面板與 `DESIGN.md` 統一風格；做出五頁網站並串成原型，按 Play 試玩、找同學試用。
> * **完成（06–07）**：AI Studio 分享連結、Netlify 發布、合併成真正的 RWD 網頁、交給 pen.dev 精修，以及用 MCP 讓 AI 控制 Stitch。

## [Claude Design 實戰：在 Claude 對話裡設計 RWD 網頁 >>](./Claude_Design實戰_Artifact設計畫布)
> Claude Design 已併入一般 Claude 對話，成為 Artifacts 的一種（免費版也能用）。本單元以「木日 Kibi 老宅咖啡一週年活動頁」貫穿，提供大量可直接複製的 Prompt：
> * **入門（01–02）**：三種開始方式、給足資料並讓 Claude 先提問、一次要求三個設計方向。
> * **核心（03–05）**：對話、評論、直接編輯三種修改方式；用設計系統（或免費版用 `DESIGN.md`）讓作品符合品牌；依網頁區塊分類的 **RWD 網頁 Prompt 範例庫**。
> * **完成（06）**：分享給客戶留評論、匯出 PDF／PPTX／HTML、交給 Claude Code 做成真正的 RWD 網站。

## [pen.dev 實戰：AI 輔助的 RWD 網頁設計畫布 >>](./pen_dev實戰與AI設計畫布)
> 由淺至深的 10 章實作教材：每一章由 AI 先產生練習素材，學生再**親手操作 pen.dev 的每一個功能**，每個觀念都附圖解，範例以 RWD 網頁為主：
> * **入門（01–03）**：認識 pen.dev 與 `.pen` 節點樹、介面與快捷鍵、形狀／文字／圖示。
> * **核心（04–07）**：Flex 自動排版（Fixed／Hug／Fill 與三種寬度版面）、元件與變體，以及從 Button 做到整頁活動頁的**網頁元件庫實戰**；用變數與主題做深色模式與 RWD 斷點。
> * **完成（08–09）**：填色、特效與 AI 生圖；用「選取＋便利貼」交棒給 AI，把設計稿轉成 RWD 網頁，並在畫布上用 `browser` 節點並排驗收。
> * **延伸（10）**：把設計稿轉成 PyQt6 桌面程式。


## [如何評估現有的網站？ >>](./如何評估現有的網站)
> 在進行網站改版與優化前，透過 AI 進行既有網站的健康檢查是至關重要的步驟。本單元引導你如何利用多模態 AI 與 **Gemini in Chrome** 內建工具對現有網站進行快速評估，內容包含：
> * **UI/UX 評估**：包含可用性啟發式評估（尼爾森十大原則）、視覺排版美學、操作動線流暢度。
> * **進階管理指標**：針對 **無障礙規範 (A11y/WCAG/NCC)**、**搜尋引擎優化 (SEO)** 與 **資訊安全 (Security)** 提供程式碼/截圖審查提示詞。
> * **實作與工具**：提供長截圖技巧、實用 Prompt 模板，以及適合課堂練習的民間商業網站名單（如台灣高鐵、104人力銀行），協助你快速生成診斷報告並無縫對接原型重構。

## [網站架構觀念 (Website Architecture) >>](./網站架構觀念)
> AI 生成畫面的速度再快，判斷「哪一版才對」的眼光仍要靠你自己。對 AI Product Builder 來說，網站核心架構知識就是這份眼光的基本功。本單元涵蓋網站從立體空間構造、版面佈局、導覽設計、一致性原則到無縫式介面與細節雕琢等六大核心維度，是確保網站專案具備優異易用性與卓越使用者體驗的基石，內容包含：
> * **立體構造與佈局**：涵蓋垂直、水平、前後的立體空間構造，以及單欄、多欄、格狀與回應式網頁（RWD）等佈局模式。
> * **導覽與一致性**：涵蓋全域、區域與麵包屑等導覽列設計原則，以及降低使用者迷路風險的介面一致性規範。
> * **互動與細節**：涵蓋不切換畫面的無縫式介面體驗，以及讓操作更加直覺極簡的設計講究之處。

## [使用 Claude Skill 強化網頁設計：8 款熱門 Skill 實測與指南 >>](./Claude網頁設計Skill實戰指南)
> 透過替 Claude 掛載 Skill（工作手冊），能顯著改變 AI 生成網頁的視覺質感與動效表現。本單元整理自 10 位選手（8 款熱門網頁設計資源 + 免費版 Claude + Claude Design Pro）的兩輪實測，內容包含：
> * **Skill 基礎與安裝排雷**：說明 Skill 運作原理、內建新增與 GitHub ZIP 單獨打包上傳的實作步驟。
> * **兩輪實測對決與推薦**：收錄 WebGL 液態咖啡／一鏡到底（免費版推薦 `UI UX Pro Max`）與開放式活動頁（付費版推薦 `Claude Design Pro`）的評比結果與完整 Prompt。
> * **最佳實踐**：解析為什麼 Skill 不是裝越多越好（額度消耗與省略機制），以及如何透過 `/` 斜線指令確保正確觸發。

## [讓 AI 做出不像 AI 的設計：Anthropic 設計師的實戰工作流 >>](./讓AI做出不像AI的設計)
> AI 生成的畫面為什麼總是米白背景、襯線字體、橘色按鈕？本單元整理 Anthropic 設計師 Nate Parrott 的實戰做法，核心只有一句話：**你給 AI 什麼，就會拿回什麼**。內容包含：
> * **先發散再收斂**：讓 AI 開工前先問問題、一次要 10 個以上方向再一輪一輪收斂，難的設計先要線框圖，大型產出先探索風格。
> * **給足脈絡、點破壞習慣**：讓 AI 讀程式碼重建現有畫面再發想，並直接告訴模型它的失敗模式，整理出可放進 `DESIGN.md` 的「AI 壞習慣清單」。
> * **延伸應用**：（選做）把 CSV 做成即時儀表板、做動畫要照顧人眼的節奏，以及把經驗做成 Skill 再用是非題做臨時 eval。


## [易用性測試：讓真實使用者告訴你哪裡不好用 >>](./易用性測試)
> 設計者永遠看不出「第一次來的人」會卡在哪裡。本單元教你用最低成本驗證原型，內容包含：
> * **測試準備與執行**：撰寫不洩漏答案的任務腳本、找 5 位符合 Persona 的受測者、以放聲思考法觀察並記錄。
> * **指標與分析**：任務成功率、任務時間、單題容易度（SEQ），並用尼爾森嚴重度分級排出修改優先順序。
> * **AI 模擬與反覆修正**：讓 AI 扮演 Persona 預演測試腳本，再把真人測試結果寫回 `DESIGN.md` 與 Figma 稿。
> * **Maze 遠端測試**：（選用）匯入 Figma 原型做無主持測試，自動統計成功率與點擊路徑，驗證修改後是否改善。

## [前端動態框架圖鑑：叫得出名字，AI 才做得出來 >>](./前端動態框架圖鑑)
> 網頁上的粒子、3D、流動背景與捲動動畫，背後幾乎都有專門的 JavaScript 框架。本單元用設計師聽得懂的語言整理四大類框架，每個框架都附 **[線上即時 demo](https://roberthsu2003.github.io/UI_UX_Prototype/frameworks.html)** 與可直接複製的 Prompt 範本，內容包含：
> * **Canvas 2D 與 3D / WebGL**：p5.js 生成藝術、PixiJS 大量粒子、Fabric.js 可編輯畫布，以及 Three.js 產品展示、Babylon.js 互動場景、Shader 液態背景。
> * **動畫與動態影片感**：GSAP 時間軸、Anime.js 交錯動畫、Lottie 播放 AE 動畫，並延伸認識 Rive 互動動畫與 Remotion 程式化影片。
> * **資料視覺化與捲動互動**：D3.js 網站架構圖、Chart.js 儀表板，以及 GSAP ScrollTrigger + Lenis 的捲動敘事手法。

## [部署 Landing Page：從本機執行到 GitHub Pages 上線 >>](./部署Landing_Page)
> 課程的最後一哩路：把 `DESIGN.md` 與 Figma 定稿變成任何人都能打開的真實網址。本單元以 **React + Vite** 建立活動頁面，全程 Vibe Coding，內容包含：
