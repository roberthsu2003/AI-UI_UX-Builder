## 🎯 產品需求規格（PRD & 資訊架構）

### 1. 專案背景與痛點
許多餐廳的手機掃碼點餐系統非常難用：點一道菜要載入新頁面、加料選項按錯不能改、或是送出後不知道廚房到底有沒有收到單。本應用追求 **零換頁、單手拇指友善（按鈕高 ≥ 44px）、即時計算金額** 的無縫體驗。

### 2. 核心功能與無縫互動需求
1. **頂部桌號識別列**：清楚顯示餐廳名「好食光食堂」、顯眼的 `桌號 A05・2 位` 膠囊標籤，以及「已點紀錄」按鈕。
2. **置頂橫向分類導覽（Sticky Tabs）**：`全部`、`主廚招牌`、`暖心飯麵`、`台味小菜`、`手作茶飲`，點擊即切換篩選或快速定位分類。
3. **餐點卡片列表（至少 8 道餐點）**：每列包含菜名、簡短介紹、售價、辣度／人氣標籤與 `+ 選擇` 按鈕。
4. **客製化底部滑出抽屜（Bottom Sheet）**：
   * 點擊餐點後從螢幕底部平滑滑出面板（附半透明遮罩）。
   * 提供「份量／辣度／甜度冰塊（單選）」、「加料區（複選：溏心蛋 +$25、起司 +$20、加飯 +$15）」、備註文字欄、數量加減，並**即時更新底部按鈕金額**（例如 `加入購物車・NT$ 215`）。
5. **底部常駐購物車浮動條 ＋ 明細結帳抽屜**：
   * 購物車非空時，固定於螢幕最下方顯示 `共 X 件｜小計 NT$ XXX｜查看訂單`。
   * 點開明細抽屜可調整品項數量或刪除，按下「送出訂單至廚房」後切換為 `✅ 廚房已接單・約 12 分鐘出餐` 確認畫面，並將明細存入「已點紀錄」。

### 3. 真實感繁體中文文案與預設素材（直接給 AI 使用）
* **預設 8 道台灣餐廳菜單**：
  1. `主廚私房紅燒牛肉麵`（主廚招牌）— `NT$ 220`｜標籤：`人氣必點`
  2. `剝皮辣椒雞湯烏龍麵`（主廚招牌）— `NT$ 210`｜標籤：`微辣暖胃`
  3. `古早味手切滷肉飯套餐`（暖心飯麵）— `NT$ 145`｜含溏心蛋與時蔬
  4. `松露奶油野菇燉飯`（暖心飯麵）— `NT$ 260`｜蛋奶素可
  5. `酥炸金沙豆腐`（台味小菜）— `NT$ 110`｜外酥內嫩鹹蛋黃
  6. `胡麻涼拌龍鬚菜`（台味小菜）— `NT$ 85`｜清爽開胃
  7. `日月潭紅玉冷泡茶（無糖）`（手作茶飲）— `NT$ 75`｜去油解膩
  8. `黑糖珍珠鮮奶（少冰）`（手作茶飲）— `NT$ 95`｜濃醇手炒黑糖

## 🎨 視覺與 `DESIGN.md` 預設規範

* **氛圍關鍵字**：食慾開胃暖調、單手極速操作、高對比清楚價格。
* **字體搭配**：`Noto Sans TC` + 價格數字強制套用 `tabular-nums` 等寬對齊。

| Token 名稱 | Hex 色碼 | 語意用途 |
| :--- | :--- | :--- |
| `canvas` | `#FAFAFA` | 潔淨微暖白背景 |
| `surface` | `#FFFFFF` | 餐點卡片與 Bottom Sheet 底色 |
| `ink` | `#1E1E1E` | 深墨黑菜名與主文字 |
| `muted` | `#666666` | 餐點描述與備註提示 |
| `primary` | `#E0522C` | 開胃暖橘紅（主按鈕、購物車浮動條、桌號強調） |
| `accent` | `#FFF1EC` | 選中加料選項的淺橘紅底色 |
| `hairline` | `#ECECEC` | 1px 分隔線 |

> [!WARNING]
> **AI 壞習慣禁令**：在桌機瀏覽器檢視時，必須置中呈現一個 `390px` 寬度模擬手機外框（手機瀏覽則自動滿版），不可拉成超寬 1440px 的單欄大表單；所有點擊元件高度至少 `44px`。

## 🤖 AI 全流程控制 Prompt 模板

### Prompt A：一鍵生成可完整互動的 Mobile Web App 點餐系統
```text
請讀取本份規格文件，為「好食光 QR Order」設計一個單手好操作的 Mobile Web App 掃碼點餐原型（單一 HTML 檔，可使用 Tailwind CSS CDN，在電腦版瀏覽器中置中以 390px 手機外框呈現）。

要求：
1. 完整內建文件提供的 8 道繁體中文菜單與加料選項。
2. 必備 JavaScript 完整互動閉環：
   - 頂部置頂顯示「桌號 A05」與橫向分類篩選 Tabs（全部 / 主廚招牌 / 暖心飯麵 / 台味小菜 / 手作茶飲）。
   - 點擊任一餐點的「+ 選擇」開啟「客製化 Bottom Sheet（底部滑出抽屜）」：可選份量（正常 / 加量 +$30）、辣度/冰塊、複選加料（溏心蛋 +$25、起司 +$20）與數量，並即時計算這筆加入金額。
   - 加入後底部出現常駐購物車浮動條（顯示總件數與小計金額）；點擊展開「訂單明細抽屜」可再加減數量，按下「送出至廚房」會把餐點轉入「已點紀錄」並顯示「廚房已接單・準備中」確認卡片！
3. 嚴格遵守配色（#FAFAFA / #1E1E1E / #E0522C）與按鈕至少 44px 高的觸控規範。
```

### Prompt B：透過 MCP 在 Figma / pen.dev 建立手機介面畫布
```text
請讀取本範例規格，透過 MCP 在畫布上建立三張並排的手機畫面（每張寬 390px、高 844px）：
1. `01_Menu_List`：含頂部桌號列、橫向分類 Tabs、菜單列表與底部購物車浮動條。
2. `02_Customize_BottomSheet`：加上半透明遮罩與圓角 20px 的底部客製化抽屜（含加料複選框與底部確認按鈕）。
3. `03_Order_Confirmed`：呈現「廚房已接單」狀態與出餐預估時間卡片。
完成後截圖檢查，確認價格數字有對齊且拇指點擊區域足夠大。
```

## ✅ 成果驗收檢核清單

- [ ] 點擊餐點後是否從底部平滑彈出客製化抽屜（Bottom Sheet），而非直接跳頁？
- [ ] 在客製化面板勾選加料或調整份量時，按鈕上的小計金額是否即時正確加減？
- [ ] 送出訂單後，購物車是否清空並可在「已點紀錄」看到剛送出的餐點與接單狀態？
- [ ] 分類標籤切換時，列表過濾是否正確？
- [ ] 畫面在 `390px` 手機尺寸下，按鈕與核取方塊是否好按不誤觸？
