## 🎯 產品需求規格（PRD & PyQt6 介面架構）

### 1. 專案背景與痛點
傳統機電監控桌面軟體常像 90 年代儀表板，滿屏紅綠閃爍令人視覺疲勞，而且看到異常數字卻沒有排查建議。本專案透過 `DESIGN.md` 規範，打造「冷靜克制、層級明確、支援一鍵匯出 CSV」的現代 B2B 監控桌面軟體。

### 2. PyQt6 介面佈局與互動規格
1. **左側固定深色垂直導覽列（240px）＋ 右側 `QStackedWidget`**：
   * 導覽項目：`即時戰情總覽`、`樓層用電明細`、`異常警報紀錄 (2)`（點擊可切換主視圖頁面，並高亮目前頁籤）。
2. **頂部控制列**：
   * 大樓切換 `QComboBox`（`台北信義總部` / `新竹研發園區`）。
   * **時間區間切換按鈕組（`今日即時` / `近 7 日` / `本月累計`）**：切換大樓或時間維度時，下方 4 張 KPI 卡與趨勢折線圖須同步切換對應數據！
   * 右上角 `匯出盤查 CSV` 按鈕（使用 `QFileDialog` 或直接寫出 CSV 並顯示底部狀態通知）。
3. **4 欄核心 KPI 數據卡**：即時總用電負載（`kW`）、累計碳排放量（`kgCO₂e`）、對比前期節電率（`%`）、目前異常警示數。
4. **中段雙欄（70% 折線圖 ＋ 30% 異常排查區）**：
   * 左欄：**`QPainter` 自繪平滑用電趨勢折線圖**（含網格座標、各時段數值點、淡青色漸層填充區域，以及一條**紅色虛線「契約容量警戒線」**）。
   * 右欄：「即時異常警示清單」，列出超標樓層卡片；點擊任一警示卡片，會在右側或彈窗顯示「AI 設備排查診斷建議」與「標記已派工處理」按鈕。
5. **樓層用電明細表**：展示 `1F`–`5F` 照明用電、空調用電、總度數與狀態徽章（`● 正常運作` / `▲ 接近警戒` / `■ 尖峰超標`，色點與文字並存）。

### 3. 真實感繁體中文素材（直接給 AI 使用）
* **台北信義總部（今日即時）**：總負載 `482 kW`｜碳排 `2,140 kgCO₂e`｜節電率 `-6.4%`｜異常 `2 件`
* **新竹研發園區（今日即時）**：總負載 `635 kW`｜碳排 `2,819 kgCO₂e`｜節電率 `+2.1%`｜異常 `1 件`
* **2 筆異常排查事件**：
  1. `5F 核心機房・空調冰水主機負載過高（+18%）` → 建議：`檢查 2 號備援冰機是否誤同步啟動，並確認冷通道擋板氣密狀態。`
  2. `3F 研發中心・離峰照明迴路未關閉（24 kW）` → 建議：`B 區會議室群組自動排程感測器離線，建議遠端重啟照明迴路控制器。`

## 🎨 視覺與 `DESIGN.md` 預設規範（轉譯為 PyQt QSS）

* **氛圍關鍵字**：冷靜工業控制室美學、克制不刺眼、結構化數據。
* **字體設定**：`"PingFang TC", "Microsoft JhengHei", "Noto Sans TC", sans-serif`。

| `DESIGN.md` Token | Hex 色碼 | PyQt6 QSS / `QPainter` 用途 |
| :--- | :--- | :--- |
| `canvas` | `#F4F6F8` | 右側戰情主區極淨冷灰白背景 |
| `sidebar` | `#0F172A` | 左側 240px 固定垂直導覽列底色 |
| `surface` | `#FFFFFF` | KPI 卡片、折線圖容器與表格底色 |
| `ink` | `#111827` | 深灰黑數據主文字 |
| `muted` | `#64748B` | 單位（kW / kgCO₂e）與座標軸刻度文字 |
| `primary` | `#0F766E` | 永續青綠色按鈕與用電折線主線 |
| `danger` | `#DC2626` | 超標警戒虛線與嚴重異常徽章 |
| `warning` | `#D97706` | 接近警戒狀態徽章 |
| `hairline` | `#E2E8F0` | `1px solid` 卡片邊框與圖表背景網格線 |

> [!WARNING]
> **PyQt6 Vibe Coding 禁令**：禁止將整張樓層或異常卡片塗滿刺眼的紅色背景；異常狀態只用淺色小膠囊（如淡紅底 `#FEE2E2` 配深紅字 `#B91C1C`）並搭配符號文字顯示。

## 🤖 AI Vibe Coding 控制 Prompt 模板

### Prompt A：一鍵生成 `DESIGN.md` 企業級監控後台 `greenpulse_app.py`
```text
請讀取 @DESIGN.md（若無則嚴格使用本規格文件的色彩 Tokens），用 Python PyQt6 結合 Vibe Coding 實作《GreenPulse 綠脈動》商辦用電與碳排監控桌面軟體，存成單一可執行的 `greenpulse_app.py`。

【程式碼與美學要求】
1. 檔案開頭定義 `TOKENS` 字典並套用完整 QSS：左側 240px 深藍黑垂直導覽列（#0F172A）＋ 右側極淨冷灰白主區域（#F4F6F8），搭配圓角白色數據卡片（1px #E2E8F0 邊框）。
2. 左側導覽選單連接 `QStackedWidget`，至少實作「即時戰情總覽」與「樓層用電明細」兩個完整分頁視圖切換。
3. 必須實作自訂 `PowerTrendChart(QWidget)` 類別，用 `QPainter`（開啟 Antialiasing）繪製平滑用電趨勢折線圖，包含座標軸數字、淡青色漸層面積填充，以及一條紅色虛線標示「契約容量警戒線」。
4. 完整互動聯動：
   - 切換「台北信義總部 / 新竹研發園區」或時間膠囊「今日即時 / 近 7 日 / 本月累計」時，4 張 KPI 卡與折線圖立即切換對應模擬曲線並重繪！
   - 點擊右側「異常警示事件」展開詳細診斷建議彈窗，可按下「標記已派工處理」更新狀態。
   - 點擊「匯出盤查 CSV」會真實生成一份 `energy_report.csv` 並顯示成功提示。
5. 完成後在終端機執行檢查確保可正常啟動。
```

### Prompt B：Vibe Coding 視覺精修指令（針對截圖二次美化）
```text
請幫我調整 `greenpulse_app.py` 的細節質感：
1. 美化頂部大樓選擇的 `QComboBox` 下拉選單，加上圓角邊框與清晰的 padding，不要用系統原生突兀的箭頭樣式。
2. 在 `PowerTrendChart` 折線圖上加入滑鼠座標偵測（`mouseMoveEvent`），當滑鼠移到某個時間點附近時，顯示一個精緻的懸浮提示框（Tooltip）標出當時的用電 kW 數值。
```
