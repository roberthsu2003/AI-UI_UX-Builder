## 🎯 產品需求規格（PRD & PyQt6 介面架構）

### 1. 專案背景與痛點
傳統餐飲 POS 系統介面往往像 20 年前的灰色表單，字小又擁擠、新進店員容易按錯加料。本專案目標是利用 `DESIGN.md` 搭配 PyQt6 QSS，做出如現代平板點餐系統般**暖色開胃、按鈕好按、即時計算金額**的質感桌面程式。

### 2. PyQt6 介面佈局與互動規格
整體採 **左右雙欄佈局（左側 65% 點餐區 ＋ 右側 35% 結帳明細面板）**：
1. **頂部狀態列**：左側餐廳名稱 `好食光食堂 POS`，中間顯示醒目膠囊標籤 `桌號 A05・內用 2 位`，右側提供 `已出單紀錄` 按鈕（點擊開啟歷史訂單彈窗）。
2. **分類切換列 ＋ 格狀餐點卡（`QScrollArea` + `QGridLayout`）**：
   * 分類按鈕：`全部`、`主廚招牌`、`暖心飯麵`、`台味小菜`、`手作茶飲`（選中狀態套用暖橘紅底色）。
   * 卡片採用 `QFrame#MenuCard`（白底、1px 細邊框、圓角 `12px`、Hover 邊框變色），顯示菜名、標籤、單價與 `+ 選擇` 按鈕。
3. **客製化加料彈窗（自訂圓角 `QDialog`）**：
   * 點擊任一餐點跳出客製化視窗：單選組（份量：`正常` / `加大 +$30`、辣度/甜度）、複選組（`溏心蛋 +$25`、`炙燒起司 +$20`、`加白飯 +$15`）、備註輸入框 `QLineEdit`、數量 `+ / -`。
   * 下方主按鈕即時顯示這筆金額（例如 `加入訂單・NT$ 215`）。
4. **右側常駐訂單明細與結帳區**：
   * 列出已選餐點、客製化備註小字、單品數量調整（`+ / -`）與移除按鈕。
   * 底部顯示大字體小計金額與滿版主要按鈕 `送出訂單至廚房`，點擊後清空購物車、存入已出單紀錄並顯示 `✅ 廚房已接單・單號 #018` 確認提示框。

## 🎨 視覺與 `DESIGN.md` 預設規範（轉譯為 PyQt QSS）

* **氛圍關鍵字**：暖白潔淨質感、開胃暖橘紅、觸控級大按鈕（`min-height: 40px`）。
* **字體設定**：`"PingFang TC", "Microsoft JhengHei", "Noto Sans TC", sans-serif`（金額數字靠右對齊）。

| `DESIGN.md` Token | Hex 色碼 | PyQt6 QSS 對應角色 |
| :--- | :--- | :--- |
| `canvas` | `#FAF9F7` | 主視窗 `QMainWindow` 暖白底色 |
| `surface` | `#FFFFFF` | 餐點卡片 `QFrame#MenuCard` 與右側明細面板底色 |
| `ink` | `#1E1E1E` | 菜名、總計金額與主要文字 |
| `muted` | `#666666` | 客製化細項備註與標籤輔助字 |
| `primary` | `#E0522C` | 開胃暖橘紅（分類選中、「送出至廚房」主按鈕、桌號膠囊） |
| `primary_hover` | `#C74320` | 主按鈕 `:hover` 加深狀態 |
| `accent` | `#FFF1EC` | 標籤與推薦項目淺橘紅底色 |
| `hairline` | `#E7E5E4` | `1px solid` 卡片邊框與面板分隔線 |

> [!WARNING]
> **PyQt6 Vibe Coding 禁令**：禁止保留 Qt 預設的系統灰色按鈕與預設醜陋框線；所有卡片與彈窗必須透過 QSS 設定圓角 `border-radius` 與充足的內距 `padding` / `contentsMargins`。
