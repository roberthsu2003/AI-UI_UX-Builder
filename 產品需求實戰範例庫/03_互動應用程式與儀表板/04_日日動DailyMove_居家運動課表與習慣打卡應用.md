## 🎯 產品需求規格（PRD & PyQt6 介面架構）

### 1. 專案背景與痛點
對長時間盯著電腦的人來說，要拿出手機找運動影片太麻煩，容易一忙就忘記起身活動。這是一個開在電腦螢幕一角就能直接按「開始計時」的**高顏值桌面微習慣應用**，用最低阻力幫助使用者每天動 15 分鐘。

### 2. PyQt6 介面佈局與互動規格
1. **頂部激勵與週進度卡片**：
   * 顯示 `🔥 已連續打卡 6 天` 徽章與「週一～週日」7 個狀態圓點（週一～週六已亮橘色，今日週日預設待完成；當今日動作全部完成時，今日圓點亮綠燈且連續天數跳成 `7 天`！）。
   * 今日目標進度條 `QProgressBar`（客製化圓角美型進度條，顯示 `已完成 X / 4 項動作`）。
2. **三套課表快速切換按鈕列**：`💻 久坐肩頸舒緩`、`🔥 15分鐘居家燃脂`、`🌙 睡前拉伸放鬆`，點擊切換下方 4 張動作任務卡片。
3. **今日動作清單（`QFrame#TaskCard`）**：
   * 每張卡片包含核取方塊 `QCheckBox`、動作名稱、簡短動作要領、建議時間標籤（如 `02:00`）與 `▶ 開始計時` 按鈕。
   * 已完成的動作卡片文字自動變淡並加上完成綠勾標示。
4. **專注倒數計時器模式（`QStackedWidget` 切換或專屬面板 ＋ `QTimer` + `QPainter`）**：
   * 點擊任一動作的 `▶ 開始計時`，切換至計時器畫面。
   * 中央使用 **`QPainter`（開啟 `Antialiasing`）繪製大圓形倒數進度環（Circular Progress Ring）**，圓環中央顯示超大清晰倒數時間（如 `02:00` → `01:59`⋯⋯，每秒平滑推進弧線）。
   * 下方提供 `暫停 / 繼續`、`一鍵完成此動作` 與 `返回清單` 大按鈕。
   * 當計時自然歸零時，**自動將該動作標記完成**、切回清單並更新進度條！
5. **達標慶祝橫幅**：4 項動作全部完成時，顯示溫暖的 `🎉 今日運動達標！連續天數 +1` 慶祝卡片。

### 3. 真實感課表預設素材（直接給 AI 使用）
* **課表一：`💻 久坐肩頸舒緩`**：
  1. `頸部側邊伸展`（`120 秒`）— 雙肩放鬆下沉，手輕扶頭部側邊停留深呼吸
  2. `胸椎開展與貓牛式`（`180 秒`）— 吸氣抬頭延展胸口，吐氣拱背放鬆下背
  3. `靠牆天使臂肩胛啟動`（`180 秒`）— 背靠牆面，手臂貼牆上下滑動喚醒上背
  4. `坐姿梨狀肌臀部伸展`（`240 秒`）— 翹起單腳呈 4 字型，身體微前傾伸展臀部
* **課表二：`🔥 15 分鐘居家燃脂`**：
  1. `開合跳熱身`（`120 秒`）、`標準深蹲循環`（`240 秒`）、`交替平板支撐`（`180 秒`）、`高抬腿與緩步收操`（`360 秒`）
* **課表三：`🌙 睡前拉伸放鬆`**：
  1. `嬰兒式全身延展`（`180 秒`）、`仰臥抱膝左右搖擺`（`120 秒`）、`仰臥脊柱扭轉`（`180 秒`）、`腹式深呼吸靜心`（`120 秒`）

## 🎨 視覺與 `DESIGN.md` 預設規範（轉譯為 PyQt QSS）

* **氛圍關鍵字**：明亮朝氣、極簡低阻力桌面工具、強烈正向反饋。
* **字體設定**：`"PingFang TC", "Microsoft JhengHei", "Noto Sans TC", sans-serif`。

| `DESIGN.md` Token | Hex 色碼 | PyQt6 QSS / `QPainter` 用途 |
| :--- | :--- | :--- |
| `canvas` | `#F9FAFB` | 主視窗純淨明亮米白背景 |
| `surface` | `#FFFFFF` | 任務卡片與計時器面板底色 |
| `ink` | `#18181B` | 深炭黑動作名稱與倒數時間文字 |
| `muted` | `#71717A` | 動作要領提示與週曆標籤 |
| `primary` | `#F97316` | 活力暖珊瑚橘（`▶ 開始計時` 按鈕、圓環進度弧線、火焰徽章） |
| `success` | `#10B981` | 青檸達成綠（完成打勾、達標慶祝卡片、今日圓點亮綠） |
| `hairline` | `#E4E4E7` | `1px solid` 卡片邊框與未完成圓環軌道色 |

> [!WARNING]
> **PyQt6 Vibe Coding 禁令**：不要用預設藍條 `QProgressBar`！必須用 QSS 設定 `QProgressBar::chunk { border-radius: 6px; background-color: #F97316; }`；`QPainter` 圓形進度環的筆畫端點請設定 `Qt.PenCapStyle.RoundCap` 才會有現代圓潤質感。

## 🤖 AI Vibe Coding 控制 Prompt 模板

### Prompt A：一鍵生成 `DESIGN.md` 活力互動應用 `dailymove_app.py`
```text
請讀取 @DESIGN.md（若無則嚴格使用本規格文件的色彩 Tokens），用 Python PyQt6 結合 Vibe Coding 實作《日日動 DailyMove》桌面運動課表與計時應用程式，存成單一可執行的 `dailymove_app.py`（預設視窗大小 480x780）。

【程式碼與美學要求】
1. 檔案開頭定義 `TOKENS` 字典並撰寫精緻的淺色 QSS（#F9FAFB 背景、#FFFFFF 圓角 14px 卡片、1px #E4E4E7 細邊框、#F97316 珊瑚橘主按鈕、#10B981 達成綠）。
2. 介面架構使用 `QStackedWidget` 分成兩頁：
   - 第 1 頁【今日課表清單】：包含「🔥 已連續打卡 6 天」與週一～週日 7 個圓點指示器、美化的進度條（已完成 X/4 項）、3 套課表切換按鈕（久坐肩頸舒緩 / 15分鐘居家燃脂 / 睡前拉伸放鬆），以及 4 張含打勾框與「▶ 開始計時」的動作卡片。
   - 第 2 頁【專注倒數計時器】：必須實作自訂 `CircularTimerWidget(QWidget)`，使用 `QPainter`（開啟 Antialiasing 並使用 `RoundCap` 圓角筆端）繪製直徑約 220px 的圓形倒數進度環，搭配 `QTimer` 每秒（或每 100ms 平滑更新）真實倒數！
3. 完整互動閉環：
   - 計時歸零（或按下「一鍵完成」）自動勾選該動作並返回第 1 頁更新進度條。
   - 當今日 4 項動作全數勾選完成時，顯示「🎉 今日運動達標！」慶祝卡片，且連續天數變成「7 天」、週日圓點亮起綠色。
4. 完成後在終端機執行檢查確保可正常啟動無報錯。
```
