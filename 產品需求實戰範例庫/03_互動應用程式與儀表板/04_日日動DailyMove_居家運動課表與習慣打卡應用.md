## 📋 專案基本定位

| 項目 | 內容規格 |
| :--- | :--- |
| **主題名稱** | 《日日動 DailyMove》每日 15 分鐘居家伸展與核心運動課表、計時器與連續打卡應用 |
| **介面類型** | `互動應用程式（跨裝置習慣追蹤工具應用 Web / Mobile App）` |
| **目標受眾 (TA)** | 久坐電腦前的上班族與學生（想養成每天 15 分鐘輕運動習慣，需要明確指引與正向成就感） |
| **核心轉換目標** | 切換今日課表、啟動倒數計時器完成動作並勾選打卡，獲得連續天數達成回饋 |
| **推薦 AI 工具** | Claude Design（即時運作倒數計時器＋微互動）、pen.dev × MCP |

## 🎯 產品需求規格（PRD & 資訊架構）

### 1. 專案背景與痛點
多數運動 App 功能太複雜，剛打開就要填體脂率、選器材或看一堆廣告課程，讓人還沒開始動就想放棄。本應用專注在**「打開就能選一套 15 分鐘課表 → 按開始計時 → 勾選完收工」**的極簡低摩擦體驗。

### 2. 核心功能與無縫互動需求
1. **連續打卡與本週進度激勵區**：
   * 顯示 `🔥 已連續運動 6 天` 徽章與「週一～週日」7 天圓點進度（今日若全部完成，今日圓點與連續天數同步亮起變成 `7 天`！）。
   * 顯示今日課表完成進度條（例如 `已完成 1 / 4 項動作`）。
2. **三套情境課表快速切換**：`💻 久坐肩頸舒緩`、`🔥 15 分鐘居家燃脂`、`🌙 睡前拉伸放鬆`，點擊切換下方 4 個動作清單與建議秒數。
3. **今日運動任務清單**：每張動作卡包含動作名稱、簡短動作要領、建議時間、`直接打勾完成` 核取方塊，以及 `▶ 開始計時` 按鈕。
4. **內建專注倒數計時器面板（必須真的能倒數！）**：
   * 點擊任一動作的 `▶ 開始計時` 後展開（或彈出）專注計時面板。
   * 顯示超大等寬數字倒數（如 `02:00` → `01:59`⋯⋯）、環形或橫向進度條、`開始 / 暫停`、`一鍵跳過完成` 與 `關閉` 按鈕。
   * 當計時自然歸零時，**自動幫該動作打勾完成**並更新今日進度條！
5. **達標慶祝回饋**：當今日 4 項動作全部勾選完成時，顯示溫暖的 `🎉 今日 15 分鐘運動達標！` 鼓勵卡片。

### 3. 真實感繁體中文文案與預設素材（直接給 AI 使用）
* **課表一：`💻 久坐肩頸舒緩`（共 12 分鐘）**：
  1. `頸部側邊伸展`（`02:00`）— 雙肩放鬆下沉，手輕扶頭部側邊停留深呼吸
  2. `胸椎開展與貓牛式`（`03:00`）— 吸氣抬頭延展胸口，吐氣拱背放鬆下背
  3. `靠牆天使臂肩胛啟動`（`03:00`）— 背靠牆面，手臂貼牆上下滑動喚醒上背肌群
  4. `坐姿梨狀肌臀部伸展`（`04:00`）— 翹起單腳呈 4 字型，身體微前傾伸展緊繃臀部
* **課表二：`🔥 15 分鐘居家燃脂`（共 15 分鐘）**：
  1. `開合跳熱身`（`02:00`）、`標準深蹲循環`（`04:00`）、`交替平板支撐`（`03:00`）、`登山者衝刺與緩步收操`（`06:00`）
* **課表三：`🌙 睡前拉伸放鬆`（共 10 分鐘）**：
  1. `嬰兒式全身延展`（`03:00`）、`仰臥抱膝左右搖擺`（`02:00`）、`仰臥脊柱扭轉`（`03:00`）、`腹式深呼吸靜心`（`02:00`）

## 🎨 視覺與 `DESIGN.md` 預設規範

* **氛圍關鍵字**：朝氣活力、極簡低阻力、正向成就感回饋。
* **字體搭配**：`Noto Sans TC` + 倒數計時器數字使用 `JetBrains Mono`（`tabular-nums`，防止秒數跳動時寬度抖動）。

| Token 名稱 | Hex 色碼 | 語意用途 |
| :--- | :--- | :--- |
| `canvas` | `#F9FAFB` | 純淨明亮米白背景 |
| `surface` | `#FFFFFF` | 動作卡與計時器面板底色 |
| `ink` | `#18181B` | 深炭黑動作名稱與大字時間 |
| `muted` | `#71717A` | 動作要領提示與週曆日期 |
| `primary` | `#F97316` | 活力暖珊瑚橘（主按鈕、連續打卡火焰、計時進度） |
| `success` | `#10B981` | 青檸達成綠（完成打勾、達標慶祝狀態） |
| `hairline` | `#E4E4E7` | 1px 細邊框 |

> [!WARNING]
> **AI 壞習慣禁令**：倒數計時器的數字**一定要設定 `font-variant-numeric: tabular-nums`**，否則每一秒倒數時數字寬度會左右閃跳；動作卡片文字應簡潔好掃描，不要塞滿冗長醫學說明。

## 🤖 AI 全流程控制 Prompt 模板

### Prompt A：一鍵生成可真實計時與打卡的互動應用
```text
請讀取本份規格文件，為居家習慣應用「日日動 DailyMove」設計一個活力極簡的互動式網頁應用程式（單一 HTML 檔，可使用 Tailwind CSS CDN，置中以 440px App 卡片寬度呈現，手機版滿版）。

要求：
1. 完整內建文件提供的三套課表（久坐肩頸舒緩 / 15分鐘居家燃脂 / 睡前拉伸放鬆）與動作秒數、要領。
2. 必備 JavaScript 真實互動功能：
   - 頂部顯示「🔥 已連續打卡 6 天」、週一到週日 7 個圓點狀態，以及今日進度條（已完成 X / 4 項）。
   - 切換課表標籤時，立即更新下方 4 個動作列表與進度計算。
   - 內建真實「專注倒數計時器」：點擊任一動作的「▶ 開始計時」，打開計時面板並以等寬大字（tabular-nums）一秒一秒真實倒數！提供「暫停 / 繼續」、「重設」、「直接完成」按鈕；若倒數至 00:00 自動將該動作打勾！
   - 當 4 個動作全部完成時，顯示「🎉 今日運動達標！」慶祝橫幅，並將連續天數亮燈加 1（變 7 天）！
3. 嚴格遵守配色（#F9FAFB / #18181B / #F97316 / #10B981），按鈕好按不誤觸。
```

### Prompt B：透過 MCP 在 Figma / pen.dev 建立跨裝置 App 畫布
```text
請讀取本範例規格，透過 MCP 在畫布上建立兩張並排的手機畫面（寬 390px）：
1. `01_Today_Workout`：含頂部連續 6 天激勵卡、7 日圓點、3 套課表切換膠囊與 4 張動作任務卡片（含「▶ 開始計時」按鈕）。
2. `02_Active_Timer`：專注倒數計時器畫面，中央放置大字號 02:45 等寬時間與進度環，下方配置寬大的「暫停」與「完成此動作」按鈕。
完成後截圖檢查，確認運動時遠看螢幕也能一眼看清倒數秒數與大按鈕。
```

## ✅ 成果驗收檢核清單

- [ ] 點擊 `▶ 開始計時` 後，計時器是否真的能一秒一秒穩定倒數（且數字寬度不左右抖動）？
- [ ] 計時歸零或手動勾選全部 4 項動作時，週進度圓點與「今日達標慶祝回饋」是否即時出現？
- [ ] 切換三套不同課表（舒緩／燃脂／睡前）時，動作清單與總時間是否正確切換？
- [ ] 視覺氛圍是否明亮有朝氣，避免繁雜的表單欄位讓使用者產生阻力？
- [ ] 手機版（`375px`）瀏覽時，所有按鈕高度是否皆足以讓邊運動的使用者輕鬆點擊？
