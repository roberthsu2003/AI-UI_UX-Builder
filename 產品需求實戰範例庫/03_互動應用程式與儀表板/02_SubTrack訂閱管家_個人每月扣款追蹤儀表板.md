## 🎯 產品需求規格（PRD & 資訊架構）

### 1. 專案背景與痛點
現代人每個月在不知不覺中累積了許多「自動續訂扣款」，直到月底收到信用卡帳單才驚覺花了好幾千元。本儀表板用最直覺的方式回答使用者兩個問題：**「我每個月到底固定流出多少錢？」** 以及 **「未來 7 天誰要扣款？」**。

### 2. 核心功能與無縫互動需求
1. **頂部工具列**：Logo `SubTrack 訂閱管家`、年繳換算月均顯示說明、右側醒目 `+ 新增訂閱` 主要按鈕。
2. **三大即時 KPI 摘要卡**：
   * `本月固定總支出（NT$）`（**隨新增／刪除項目即時加總變動！**）
   * `目前有效訂閱數`（例如 `6 項服務`）
   * `7 日內即將扣款總額`（突顯近期扣款警示）
3. **雙欄分析圖表區**：
   * 左欄：使用 **Chart.js** 繪製「各分類月支出佔比」環圈圖（Doughnut Chart），當新增或刪除項目時圖表要同步重繪！
   * 右欄：「即將扣款提醒列表」，列出倒數 7 天內要扣款的項目與橘色警告倒數標籤（如 `2 天後扣款`）。
4. **訂閱項目明細清單與篩選**：
   * 分類篩選按鈕：`全部`、`AI 生產力`、`影音娛樂`、`雲端與工具`。
   * 關鍵字搜尋框。
   * 每列顯示服務名稱、分類標籤、扣款週期、折合每月金額（`NT$`）與「刪除／取消追蹤」按鈕。
5. **「+ 新增訂閱」彈出視窗（Modal）**：輸入服務名稱、分類、金額、計費週期（每月 / 每年，若選每年自動除以 12 算入月支出）、距離下次扣款天數；送出後即時寫入清單並更新上方 KPI、提醒列表與 Chart.js 圖表！

### 3. 真實感繁體中文文案與預設素材（直接給 AI 使用）
* **預設 6 筆台灣使用者常見訂閱資料**：
  1. `Claude Pro`｜分類：`AI 生產力`｜`NT$ 650 / 月`｜下次扣款：`2 天後`
  2. `Figma Professional`｜分類：`AI 生產力`｜`NT$ 480 / 月`｜下次扣款：`5 天後`
  3. `Netflix 高級方案`｜分類：`影音娛樂`｜`NT$ 460 / 月`｜下次扣款：`11 天後`
  4. `YouTube Premium`｜分類：`影音娛樂`｜`NT$ 199 / 月`｜下次扣款：`18 天後`
  5. `iCloud+ 2TB`｜分類：`雲端與工具`｜`NT$ 300 / 月`｜下次扣款：`4 天後`
  6. `Notion Plus（年繳換算）`｜分類：`雲端與工具`｜`NT$ 3,600 / 年（約 NT$ 300/月）`｜下次扣款：`24 天後`

## 🎨 視覺與 `DESIGN.md` 預設規範

* **氛圍關鍵字**：現代個人 Fintech 深色儀表板（Linear / Stripe 俐落質感）、高數字掃描效率。
* **字體搭配**：`Noto Sans TC` + `Inter` + 金額數字強制 `JetBrains Mono`（`tabular-nums`）。

| Token 名稱 | Hex 色碼 | 語意用途 |
| :--- | :--- | :--- |
| `canvas` | `#0F172A` | 深曜石藍黑儀表板底色 |
| `surface` | `#1E293B` | KPI 卡片、圖表區與列表底色 |
| `ink` | `#F8FAFC` | 柔白主文字與金額大數字 |
| `muted` | `#94A3B8` | 次要週期與分類說明 |
| `primary` | `#38BDF8` | 天空青藍主要操作按鈕與高亮狀態 |
| `warning` | `#F59E0B` | 7 日內即將扣款警示標籤（琥珀橘） |
| `hairline` | `#334155` | 1px 卡片細邊框 |

> [!WARNING]
> **AI 壞習慣禁令**：禁止做「假數據死圖」（新增訂閱後上方總金額與圖表都不動）；金額一律靠右對齊且加上千分位逗號（如 `NT$ 2,389`）。

## 🤖 AI 全流程控制 Prompt 模板

### Prompt A：一鍵生成可真實計算與繪圖的 Web App 儀表板
```text
請讀取本份規格文件，為「SubTrack 訂閱管家」設計一個功能完整、數據完全聯動的現代深色儀表板 Web App（單一 HTML 檔，可使用 Tailwind CSS CDN 與 Chart.js CDN）。

要求：
1. 預設載入文件提供的 6 筆真實訂閱資料，所有計算（月支出總額、有效數量、7 日內即將扣款額與項目）必須由 JavaScript 動態運算，不可寫死假數字！
2. 繪製「各分類月支出佔比」Chart.js 環圈圖（Doughnut Chart），年繳項目須自動除以 12 換算成月均金額計入。
3. 完整實作「分類篩選、關鍵字搜尋、單筆刪除、以及『+ 新增訂閱』Modal 表單」：當使用者新增或刪除任何一筆訂閱時，上方 3 張 KPI 卡片、7 日內扣款提醒、明細表格與 Chart.js 圖表必須同步即時更新！
4. 嚴格遵守深色 Fintech 配色（#0F172A / #1E293B / #38BDF8 / #F59E0B）與等寬數字對齊。
```

### Prompt B：透過 MCP 在 Figma / pen.dev 建立儀表板畫布
```text
請讀取本範例規格，透過 MCP 在畫布上建立「SubTrack 訂閱管家」桌機版儀表板（1440px × 900px）：
1. 頂部工具列（含 `+ 新增訂閱` 按鈕）、3 張等寬 KPI 卡片列。
2. 中段雙欄（左 45% 環圈圖卡片、右 55% 近期扣款提醒列表），下方為完整的訂閱明細列表表格。
3. 使用深曜石色系（#0F172A / #1E293B）搭 1px #334155 細邊框與 #38BDF8 強調色，完成後截圖檢查數字對齊與文字對比度。
```
