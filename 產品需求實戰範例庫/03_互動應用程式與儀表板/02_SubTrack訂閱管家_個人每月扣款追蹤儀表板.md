## 🎯 產品需求規格（PRD & PyQt6 介面架構）

### 1. 專案背景與痛點
現代人每個月在不知不覺中累積許多自動續訂扣款。這套桌面管家讓使用者打開軟體就能清楚看見：**「每月固定總支出是多少？」**、**「哪個類別佔比最高？」** 以及 **「未來 7 天誰要扣款？」**。

### 2. PyQt6 介面佈局與互動規格
1. **頂部工具列**：左側標題 `SubTrack 訂閱管家` 與副標「掌握每一筆自動續訂支出」，右側分類篩選按鈕列（`全部`、`AI 生產力`、`影音娛樂`、`雲端與工具`）＋ 醒目 `+ 新增訂閱` 主按鈕。
2. **三大即時 KPI 摘要卡（頂部 3 欄 `QFrame#KpiCard`）**：
   * `本月預估總支出`（`NT$ X,XXX` — **年繳項目自動除以 12 計入，新增/刪除即時重算！**）
   * `目前有效訂閱數`（`X 項服務`）
   * `7 日內即將扣款`（顯示金額與項目數，以琥珀橘強調）
3. **中段雙欄視覺分析區（45% / 55%）**：
   * 左欄：**`QPainter` 自繪「各分類支出佔比」環圈圖（Doughnut Chart）**（開啟 `Antialiasing` 抗鋸齒，中央顯示總額、右側顯示色塊圖例與百分比；資料異動時呼叫 `update()` 即時重繪！）。
   * 右欄：「7 日內即將扣款提醒列表」，列出最近到期服務與倒數天數膠囊標籤（如 `2 天後扣款`）。
4. **下方訂閱明細表（自訂樣式 `QTableWidget` 或滾動清單卡片）**：
   * 支援上方分類按鈕與關鍵字搜尋框 `QLineEdit` 篩選。
   * 每列顯示服務名稱、分類徽章、計費週期、折合月均金額（靠右對齊）、下次扣款天數與「刪除」按鈕（點擊刪除立刻重算上方 KPI 與重繪環圈圖）。
5. **「+ 新增訂閱」`QDialog` 彈窗**：輸入名稱、分類下拉選單 `QComboBox`、金額、週期（每月／每年）、距離下次扣款天數，按下儲存立即更新主畫面所有數據與圖表。

### 3. 真實感預設訂閱素材（直接給 AI 使用）
1. `Claude Pro`｜`AI 生產力`｜`NT$ 650 / 月`｜下次扣款：`2 天後`
2. `Figma Professional`｜`AI 生產力`｜`NT$ 480 / 月`｜下次扣款：`5 天後`
3. `Netflix 高級方案`｜`影音娛樂`｜`NT$ 460 / 月`｜下次扣款：`11 天後`
4. `YouTube Premium`｜`影音娛樂`｜`NT$ 199 / 月`｜下次扣款：`18 天後`
5. `iCloud+ 2TB`｜`雲端與工具`｜`NT$ 300 / 月`｜下次扣款：`4 天後`
6. `Notion Plus`｜`雲端與工具`｜`NT$ 3,600 / 年（折合 NT$ 300/月）`｜下次扣款：`24 天後`

## 🎨 視覺與 `DESIGN.md` 預設規範（轉譯為 PyQt QSS）

* **氛圍關鍵字**：深色 Fintech 質感（Linear / Stripe 風格）、低視覺疲勞、高對比數字。
* **字體設定**：`"PingFang TC", "Microsoft JhengHei", "Noto Sans TC", sans-serif` + 金額數字設定等寬或對齊顯示。

| `DESIGN.md` Token | Hex 色碼 | PyQt6 QSS / `QPainter` 用途 |
| :--- | :--- | :--- |
| `canvas` | `#0F172A` | 主視窗深曜石藍黑底色 |
| `surface` | `#1E293B` | KPI 卡片、環圈圖外框與明細面板底色 |
| `surface_hover` | `#263349` | 表格列懸停微亮底色 |
| `ink` | `#F8FAFC` | 柔白標題與大字金額 |
| `muted` | `#94A3B8` | 分類副標、週期說明 |
| `primary` | `#38BDF8` | 天空青藍（`+ 新增訂閱` 按鈕與選中篩選標籤） |
| `warning` | `#F59E0B` | 7 日內即將扣款警示標籤（琥珀橘） |
| `hairline` | `#334155` | `1px solid` 卡片邊框與表格分隔線 |

> [!WARNING]
> **PyQt6 Vibe Coding 禁令**：禁止使用預設刺眼的亮白 `QTableWidget` 格子線！必須透過 QSS 隱藏原生格線並客製化 `QHeaderView::section` 成深色質感；`QPainter` 繪製環圈圖務必開啟 `QPainter.RenderHint.Antialiasing`。

## 🤖 AI Vibe Coding 控制 Prompt 模板

### Prompt A：一鍵生成 `DESIGN.md` 深色質感 `subtrack_app.py`
```text
請讀取 @DESIGN.md（若無則嚴格套用本規格文件的深色 Fintech Tokens），用 Python PyQt6 結合 Vibe Coding 實作《SubTrack 訂閱管家》桌面儀表板應用程式，存成單一可執行的 `subtrack_app.py`。

【程式碼與美學要求】
1. 開頭定義 `TOKENS` 字典並撰寫完整深色系 QSS（#0F172A 背景、#1E293B 圓角卡片、1px #334155 細框線、#38BDF8 主按鈕），把 `QTableWidget` 表頭與列距徹底美化，不可出現白色背景或醜陋預設框線。
2. 內建文件提供的 6 筆真實訂閱資料（含年繳自動除以 12 換算月均邏輯）。
3. 必須實作一個繼承 `QWidget` 的自訂類別 `CategoryDonutChart`，使用 `QPainter` 加上 `QPainter.RenderHint.Antialiasing` 抗鋸齒繪製精緻的「各分類月支出佔比環圈圖」，中央顯示本月總支出，右側顯示分類色塊與百分比圖例！
4. 完整互動閉環：
   - 頂部分類按鈕與搜尋框可即時過濾下方表格。
   - 點擊「+ 新增訂閱」跳出深色圓角 `QDialog` 新增資料；點擊每列「刪除」按鈕移除資料。
   - 只要資料新增或刪除，頂部 3 張 KPI 卡片、7 日內扣款提醒、明細表與 `CategoryDonutChart` 環圈圖必須同步即時重算並重繪！
5. 完成後在終端機測試語法與啟動確認無錯誤。
```

### Prompt B：Vibe Coding 視覺精修指令（針對截圖二次美化）

請幫我優化 `subtrack_app.py` 的兩個視覺細節：
