當產品進入 **應用程式（Mobile Web App / Web App / Dashboard）** 階段，使用者的任務從「看資訊」轉變為「高頻率點選、填寫表單、篩選數據與即時更新狀態」。這類題目最考驗你對 [無縫式介面](../../網站架構觀念/無縫式介面/README.md) 與狀態回饋的控制能力。

---

## 💡 用 AI 設計互動應用程式的三大控制重點

1. **真實可用狀態（而不只是假圖）**：用 AI 生成原型時，務必明確要求 JavaScript 狀態連動——例如「新增項目後上方 KPI 總額要同步重新計算」、「倒數計時器真的能一秒一秒倒數」。
2. **無縫式介面取代整頁重整**：大量運用 **Bottom Sheet（手機底部滑出抽屜）**、**右側診斷抽屜**、**Overlay Modal** 與 **Toast 提示**。
3. **數字對齊與狀態識別**：所有金額、電量、時間數字要求加上 `tabular-nums` 等寬對齊；異常與狀態標籤不可只靠顏色，必須同時加上文字與圖示。
