## 🎯 產品需求規格（PRD & 資訊架構）

### 1. 專案背景與痛點
台灣職場開會經常出現「中英夾雜（晶晶體）」甚至偶爾穿插台語，國外會議軟體辨識率極低，導致 PM 會後仍要花 1 小時重聽錄音整理 Action Items。NoteFlow AI 主打針對台灣口音優化，會後 30 秒生成結構化摘要並自動指派待辦事項。

### 2. 頁面必備區塊與架構
1. **頂部導覽列**：Logo、功能特色、價格方案、常見問題、「登入」與「免費試用 14 天」按鈕。
2. **首屏 Hero ＋ 產品介面預覽卡（Product Mockup）**：左或上為核心主張與雙按鈕，下方展示一個擬真的「會議紀錄雙欄預覽界面」（左邊顯示中英夾雜逐字稿片段，右邊顯示自動提取的待辦勾選清單與負責人標籤）。
3. **Before / After 痛點對比區**：對照「傳統人工整理 60 分鐘」與「NoteFlow AI 30 秒自動化」。
4. **三大核心賣點 Bento Grid**：中英夾雜高準度、自動抽取待辦並同步 Notion／Slack、一鍵開立台灣三聯式發票。
5. **互動式價格方案（Pricing Table）**：具備「月繳 / 年繳（省 20%）」切換開關（Toggle），切換時三種方案的價格數字需即時動態更新！
6. **手風琴常見問題（FAQ Accordion）**：5 題可點擊展開／收合。

### 3. 真實感繁體中文文案與預設素材（直接給 AI 使用）
* **主標語**：`開完會，會議紀錄與待辦清單也寫好了。`
* **副標語**：`專為台灣職場「中英夾雜」口音訓練的 AI 會議助理，30 秒產出逐字稿、決議摘要並同步至 Slack 與 Notion。`
* **Mockup 示範內容**：
  * 逐字稿片段：`Alex：這週五前先把 Design Token 的 PR merge 進來，下週一跟客戶 demo 時要確保手機版不會破版。`
  * AI 抽取待辦：`[ ] 完成 Design Token PR 合併（負責人：Alex・期限：週五 18:00）`
* **價格方案數據**：
  1. `個人體驗版`：月繳 `NT$ 0` ／ 年繳 `NT$ 0`（每月 120 分鐘錄音轉寫、基本摘要匯出）
  2. `Pro 團隊版（最受歡迎）`：月繳 `NT$ 390 / 人` ／ 年繳 `NT$ 310 / 人`（無限時數轉寫、Notion／Slack 雙向同步、團隊共用詞庫）
  3. `企業客製版`：月繳 `NT$ 890 / 人` ／ 年繳 `NT$ 710 / 人`（私有雲部署、SSO 單一登入、台灣三聯式發票與專屬顧問）
* **FAQ 5 題**：支援中英台語混雜嗎？錄音資料會用來訓練公開模型嗎？可以匯出哪些格式？支持免費試用後取消嗎？企業報帳可開立台灣統一編號發票嗎？

## 🎨 視覺與 `DESIGN.md` 預設規範

* **氛圍關鍵字**：俐落乾淨的現代 SaaS 生產力風、高可讀性、克制專業感。
* **字體搭配**：`Noto Sans TC` + `Inter`（數字使用等寬 `JetBrains Mono` / `tabular-nums`）。

| Token 名稱 | Hex 色碼 | 語意用途 |
| :--- | :--- | :--- |
| `canvas` | `#F8FAFC` | 清爽極簡冷白畫布 |
| `surface` | `#FFFFFF` | 卡片與價格表底色 |
| `ink` | `#0F172A` | 深石板灰主標題與內文 |
| `muted` | `#475569` | 次要說明與方案細項 |
| `primary` | `#0D9488` | 沉穩青碧綠主 CTA 與高亮邊框 |
| `accent` | `#ECFDF5` | 重點推薦標籤與淺綠底色 |
| `hairline` | `#E2E8F0` | 1px 細框線 |

> [!WARNING]
> **AI 壞習慣禁令**：禁止使用千篇一律的紫藍色漸層背景與發光霓虹卡片；Pricing 推薦方案用明確邊框與標籤突顯，不靠過度浮誇的陰影。

## 🤖 AI 全流程控制 Prompt 模板

### Prompt A：一鍵生成可互動單頁原型
```text
請讀取本份規格文件，為台灣 SaaS 產品「NoteFlow AI」製作高轉換率 Landing Page（單一 HTML 檔，可使用 Tailwind CSS CDN）。

要求：
1. 使用文件內提供的「真實中文文案、Mockup 逐字稿示範、三方案價格與 5 題 FAQ」。
2. 必備 JavaScript 互動功能：
   - 價格方案的「月繳 / 年繳享 8 折」切換開關（Toggle）：點擊切換時，三欄價格卡片的數字（如 NT$ 390 ↔ NT$ 310）與計費說明文字需即時更新！
   - FAQ 手風琴（Accordion）：點擊問題標題平滑展開解答並旋轉箭頭圖示。
3. 首屏下方的「會議摘要介面 Mockup」須用純 HTML/CSS 精細繪製，看起來像真實軟體截圖。
4. 嚴格遵守配色（#F8FAFC / #0F172A / #0D9488），禁止紫藍漸層。
```

### Prompt B：透過 MCP 在 Figma / pen.dev 建立畫布與局部精修
```text
請讀取本範例規格，透過 MCP 在畫布中建立「NoteFlow AI 首屏 + 價格方案區」：
1. 首屏（1440px）須包含頂部導覽列、置中 Hero 標題與雙按鈕，以及下方佔寬 1000px 的雙欄軟體界面 Mockup 畫框。
2. 價格方案區使用 3 欄 Auto Layout 等高卡片排列，中間「Pro 團隊版」套用 2px primary 色外框與頂部「最受歡迎」膠囊標籤。
3. 完成後請截圖檢查，確認價格數字有對齊且卡片高度一致。
```
