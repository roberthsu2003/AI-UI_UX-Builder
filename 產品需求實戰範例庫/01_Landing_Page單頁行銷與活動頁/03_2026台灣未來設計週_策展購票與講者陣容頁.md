## 🎯 產品需求規格（PRD & 資訊架構）

### 1. 專案背景與痛點
每年秋季於台北松山文創園區舉辦的三天設計盛會，今年主題聚焦「AI Product Builder 與設計畫布革命」。活動頁需要兼顧強烈的策展海報視覺張力，同時讓參加者不用來回開十幾個分頁，一頁就能看完講者陣容、切換 3 天議程並完成選票。

### 2. 頁面必備區塊與架構
1. **Sticky 頂部導覽列**：活動標誌 `FDW 2026`、講者陣容、三天議程、購票方案、右側高亮「立即購票」按鈕。
2. **超大字級策展主視覺（Typography-driven Hero）**：清楚標註時間地點（`2026.10.16 — 10.18｜台北松山文創園區 1–4 號倉庫`）、活動標語與早鳥優惠倒數標籤。
3. **重磅講者陣容 Grid**：`3×2` 格狀卡片展示 6 位講者（含頭像佔位、姓名、頭銜、公司、分享主題標籤，Hover 有微幅邊框高亮效果）。
4. **互動式三天議程時間表（Tabs 切換）**：提供 `Day 1：AI 與設計系統`、`Day 2：互動與動態美學`、`Day 3：MCP 實戰工作坊` 三個頁籤，點擊立即切換時間軸議程（含時間、講題、廳別標籤）。
5. **三欄票種比較 ＋ 購票 Modal**：學生通行票、單日論壇票、三日全通早鳥票；點擊「選擇此票種」彈出購票確認 Modal（顯示已選票種、張數 `+ / -` 與總金額計算）。

### 3. 真實感繁體中文文案與預設素材（直接給 AI 使用）
* **主標語**：`RETHINK THE CANVAS：當設計走進 AI 與程式碼的邊界`
* **6 位假想講者名單**：
  1. `林書宇` — 設計系統架構師｜某科技公司（講題：`用 DESIGN.md 管住十個 AI 代理`）
  2. `陳品希` — Design Engineer｜獨立工作室（講題：`從 Figma 到 pen.dev 的無痛轉型`）
  3. `張家豪` — 資深產品總監｜跨境電商平台（講題：`AI 時代的 PM 評估與測試方法論`）
  4. `黃芷萱` — 創意技術總監｜數位互動團隊（講題：`Three.js 與 GSAP 打造會呼吸的捲動敘事`）
  5. `許哲維` — 前端架構師｜SaaS 新創（講題：`Figma MCP 到 React 元件庫的實戰踩雷`）
  6. `吳佳穎` — UX 研究員｜金融科技集團（講題：`AI 預演與真人 5 人易用性測試對照`）
* **三種票券規格**：
  1. `學生通行票（限大專在學）`：`NT$ 1,200`（三日論壇演講入場、電子證書）
  2. `單日論壇票（任選一天）`：`NT$ 2,400`（單日全場演講、含當日茶點與簡報下載）
  3. `三日全通早鳥票（最推薦）`：`NT$ 4,800`（原價 NT$ 6,500｜含 Day 3 實作工作坊與專屬紀念徽章）

## 🎨 視覺與 `DESIGN.md` 預設規範

* **氛圍關鍵字**：前衛策展海報感、深色高對比、幾何 1px 細框線排版（Swiss / Brutalist Grid）。
* **字體搭配**：`Noto Sans TC` + `Inter` + 場次時間使用 `JetBrains Mono`。

| Token 名稱 | Hex 色碼 | 語意用途 |
| :--- | :--- | :--- |
| `canvas` | `#0B0C10` | 深炭黑主背景 |
| `surface` | `#15171E` | 講者卡與票券卡底色 |
| `ink` | `#F4F4F5` | 高對比柔白主文字 |
| `muted` | `#A1A1AA` | 次要說明與廳別文字 |
| `primary` | `#C6F91F` | 高識別度萊姆螢光綠（CTA 與選中狀態，搭配深色文字 `#0B0C10`） |
| `hairline` | `#272A36` | 1px 幾何分隔線與卡片外框 |

> [!WARNING]
> **AI 壞習慣禁令**：在螢光綠按鈕（`#C6F91F`）上**絕對禁止使用白色文字**（對比度會嚴重不足），必須使用深色文字 `#0B0C10`；禁止加入無關緊要的閃爍霓虹動畫影響議程閱讀。

## 🤖 AI 全流程控制 Prompt 模板

### Prompt A：一鍵生成可互動單頁原型
```text
請讀取本份規格文件，為「2026 台灣未來設計週」製作深色前衛策展風格的活動售票 Landing Page（單一 HTML 檔，可使用 Tailwind CSS CDN）。

要求：
1. 完整使用文件內的「6 位講者名單、三天議程結構與三種票券定價」。
2. 必備 JavaScript 互動功能：
   - 議程 Tabs 切換：點擊 Day 1 / Day 2 / Day 3 頁籤，即時切換顯示當天至少 4 個時段的議程時間軸。
   - 購票確認 Modal：點擊任一票種的「選擇此票種」按鈕時，開啟 Modal 顯示票券名稱、單價，並提供張數「+ / -」調整與即時計算應付總額，按下「確認報名」顯示模擬成功憑證。
3. 嚴格遵守深色系規範：背景 #0B0C10、卡片 #15171E、1px 細框線 #272A36、高亮色 #C6F91F（螢光綠按鈕內文字必須使用 #0B0C10 確保對比度）。
```

### Prompt B：透過 MCP 在 Figma / pen.dev 建立畫布與局部精修
```text
請讀取本範例規格，透過 MCP 在畫布上設計「2026 台灣未來設計週」的 Hero 與三天議程區塊（1440px）：
1. Hero 區採用大字體排版（H1 至少 64px）與 1px 細格線劃分活動日期、地點與「立即購票」按鈕。
2. 講者區採用 3 欄 2 列整齊對齊的 Auto Layout 格線卡片。
3. 完成後請截圖檢查，確保螢光綠按鈕上的深色文字清晰易讀，沒有誤用白字。
```

## ✅ 成果驗收檢核清單

- [ ] 螢光綠按鈕上的文字是否為深炭黑色（`#0B0C10`），閱讀對比度是否清晰？
- [ ] 點擊 `Day 1 / Day 2 / Day 3` 頁籤能否不重整頁面直接切換對應議程？
- [ ] 點擊票種後彈出的購票 Modal 能否正確加減張數並計算總金額？
- [ ] 1px 幾何框線在深色背景上的對齊與留白是否具有現代策展感，而非雜亂無章？
- [ ] 切換至 `375px` 手機寬度時，講者卡片與票券卡片是否整齊收合為單欄？
