## 🎯 產品需求規格（PRD & 資訊架構）

### 1. 專案背景與痛點
台灣原創居家香氛品牌「山霧 ShanWu」推出全新「茶韻森林系列」室內擴香與大豆蠟燭，但線上買香氛最大痛點是**「聞不到味道」**。因此網頁必須用清晰的「前、中、後調視覺化圖鑑」與「適用空間場景」來降低購買猶豫，並透過即時募資進度與早鳥限時名額提升轉換。

### 2. 頁面必備區塊與架構
1. **頂部簡約導覽列**：品牌標誌 `山霧 ShanWu`、香氣圖鑑、在地工藝、早鳥方案、右側「立即贊助」按鈕。
2. **首屏雙欄（產品視覺 ＋ 募資即時進度卡）**：左側為沉靜產品主視覺與標題；右側顯示募資達成進度條（`380%`）、已募得金額（`NT$ 1,140,000`）、贊助人數與倒數天數。
3. **三款香氣互動圖鑑切換器（Scent Explorer）**：點擊切換《晨霧金萱》、《雨後紅檜》、《夜煮老茶》，動態更新前／中／後調植物成分、茶香／木質／清新三項濃度進度條，以及建議擺放空間（書房／玄關／臥室）。
4. **在地工藝與永續故事區**：介紹南投契作茶園低溫萃取與可替換式回收玻璃瓶設計。
5. **早鳥回饋方案選擇卡片**：3 組方案（單入體驗組、雙入送禮組、全系列收藏組），顯示原價劃線、早鳥價、剩餘名額，點擊方案可開啟模擬贊助確認視窗。

### 3. 真實感繁體中文文案與預設素材（直接給 AI 使用）
* **主標語**：`把一座雨後的台灣茶山，安放進你的房間。`
* **募資數據**：`目標金額 NT$ 300,000｜已募得 NT$ 1,140,000（380%）｜412 人贊助｜倒數 18 天`
* **三款香氣資料庫**：
  1. `01 晨霧金萱` — 前調：`佛手柑、山泉露水` ／ 中調：`阿里山金萱茶、白玉蘭` ／ 後調：`白雪松、白麝香` ｜ 推薦空間：`客廳與採光書房`
  2. `02 雨後紅檜` — 前調：`青檸皮、冷杉針葉` ／ 中調：`台灣紅檜、潮濕青苔` ／ 後調：`岩蘭草、檀香` ｜ 推薦空間：`玄關與工作冥想角`
  3. `03 夜煮老茶` — 前調：`烘焙紅茶葉、肉豆蔻` ／ 中調：`陳年老烏龍、琥珀` ／ 後調：`零陵香豆、癒創木` ｜ 推薦空間：`臥室與睡前閱讀時光`
* **三個回饋方案**：
  1. `單入體驗組（早鳥 78 折）`：`NT$ 1,280`（原價 NT$ 1,650｜任選擴香 150ml 一瓶｜剩餘 42 組）
  2. `雙入山林禮盒組（最受歡迎・72 折）`：`NT$ 2,380`（原價 NT$ 3,300｜任選兩款附手工棉紙禮盒｜剩餘 19 組）
  3. `全系列典藏三入組（68 折）`：`NT$ 3,360`（原價 NT$ 4,950｜三款齊全加贈補充瓶 100ml｜剩餘 8 組）

## 🎨 視覺與 `DESIGN.md` 預設規範

* **氛圍關鍵字**：東方極簡禪意（Zen Minimalism）、呼吸留白、霧面自然質感。
* **字體搭配**：標題 `Noto Serif TC` ＋ 內文 `Noto Sans TC`。

| Token 名稱 | Hex 色碼 | 語意用途 |
| :--- | :--- | :--- |
| `canvas` | `#F6F5F0` | 宣紙霧白主背景 |
| `surface` | `#FFFFFF` | 方案與圖鑑卡片底色 |
| `surface_alt` | `#EAE8E0` | 工藝段落淡石色背景 |
| `ink` | `#232824` | 深茶墨色主要文字 |
| `muted` | `#5F6660` | 次要香調與輔助文字 |
| `primary` | `#4A5D4E` | 苔蘚森綠主 CTA 與進度條色 |
| `accent` | `#A67C52` | 茶琥珀微調強調標籤 |
| `hairline` | `#D8D6CE` | 1px 細框線 |

> [!WARNING]
> **AI 壞習慣禁令**：禁止使用高飽和霓虹綠或刺眼亮橘色；保持寬裕段落間距（`80px` 以上），不可將商品細節塞成擁擠的購物平台表格。

## 🤖 AI 全流程控制 Prompt 模板

### Prompt A：一鍵生成可互動單頁原型
```text
請讀取本份規格文件，為台灣香氛品牌「山霧 ShanWu」製作東方極簡美學的新品募資預購 Landing Page（單一 HTML 檔，可使用 Tailwind CSS CDN）。

要求：
1. 完整使用文件內的「募資數據、三款香氣前中後調資料與三個早鳥回饋方案」。
2. 必備 JavaScript 互動功能：
   - 氣味圖鑑切換器（Scent Explorer）：點擊「晨霧金萱 / 雨後紅檜 / 夜煮老茶」按鈕，即時平滑更新前中後調文字、茶香／木質／清新濃度進度條，以及推薦使用空間。
   - 回饋方案選擇 Modal：點擊任一早鳥方案按鈕，開啟確認贊助視窗，允許選擇想要搭配的香氣口味並顯示模擬訂單編號。
3. 嚴格遵守色彩系統（#F6F5F0 / #232824 / #4A5D4E）與大留白節奏。
```

### Prompt B：透過 MCP 在 Figma / pen.dev 建立畫布與局部精修
```text
請讀取本範例規格，透過 MCP 在畫布上建立「山霧 ShanWu 募資首屏 + 氣味圖鑑切換區塊」：
1. 首屏採雙欄不對稱 Auto Layout（左側 55% 產品主視覺佔位與標語，右側 45% 募資進度卡片含進度條與贊助按鈕）。
2. 氣味圖鑑區上方設計 3 個水平排列 Tab 按鈕，下方展開前中後調三欄結構與濃度進度條。
3. 完成後截圖檢查，確認 Noto Serif TC 標題質感與大片留白未被破壞。
```

## ✅ 成果驗收檢核清單

- [ ] 首屏右側募資進度卡是否能一眼看清「已募得金額、達成百分比進度條與倒數天數」？
- [ ] 點擊三款香調切換按鈕時，前中後調與濃度條是否皆有對應變化？
- [ ] 整體視覺留白是否夠寬裕，展現出精品香氛的沉靜感而非廉價拍賣頁？
- [ ] 早鳥方案卡的原價刪除線、折扣標籤與剩餘名額層級是否清晰易掃描？
- [ ] 手機版（`375px`）瀏覽時，首屏與方案卡片是否整齊垂直堆疊且無文字溢出？
