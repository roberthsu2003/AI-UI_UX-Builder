## 🎯 產品需求規格（PRD & 資訊架構）

### 1. 專案背景與痛點
位於台南中西區老巷內的兩層樓老宅咖啡館「木日 Kibi」即將迎來開幕一週年，希望推出專屬活動頁吸引熟客回流並曝光週年限定優惠，同時避免傳統咖啡店網頁「只有一張海報圖、訂位還要跳去外部表單」的斷裂體驗。

### 2. 頁面必備區塊與架構
1. **Sticky 頂部導覽列**：左側品牌標誌 `木日 Kibi`，中間錨點（空間故事、限定風味、活動優惠、門市資訊），右側主要 CTA 按鈕「立即訂位」。
2. **首屏主視覺（Hero）**：呈現老宅木質光影氛圍、活動標語、期間標籤（`2026.11.20 — 11.30`）與雙按鈕（「立即訂位」Primary + 「探索限定豆」Secondary）。
3. **品牌空間故事**：雙欄圖文交錯排版，講述老宅修復與慢手沖理念。
4. **週年優惠橫幅 ＋ 三款限定單品卡**：醒目展示「全品項咖啡第二杯半價」活動規則，並以 3 欄卡片展示限定咖啡豆。
5. **無縫式訂位抽屜（Slide-over Drawer）**：點擊任何「立即訂位」不跳轉頁面，從右側平滑滑出訂位面板（含半透明遮罩、日期、時段選擇、人數與聯絡方式，送出後直接切換為預約成功確認單）。
6. **門市資訊與頁尾**：地址、營業時間、公休日、交通提醒與社群連結。

### 3. 真實感繁體中文文案與預設素材（直接給 AI 使用）
* **主標語**：`老宅裡的日常微光：木日 Kibi 開店一週年`
* **副標語**：`推開台南巷弄裡的五十歲老檜木門，在手沖水柱的蒸氣裡，與我們共度第一個冬日週年。`
* **限定活動規則**：`11/20 至 11/30 來店內用或外帶，任選咖啡全品項享第二杯半價（以價低者計）；購買限定配方豆再贈手沖濾紙乙包。`
* **3 款週年限定品項**：
  1. `冬日老宅配方・中深焙`（NT$ 420 / 半磅）— 風味：`黑巧克力、烤核桃、焦糖尾韻`
  2. `阿里山鄒築園水洗・淺焙`（NT$ 580 / 半磅）— 風味：`白桃、烏龍茶感、蜂蜜甜感`
  3. `衣索比亞日曬古吉・中淺焙`（NT$ 480 / 半磅）— 風味：`藍莓果醬、玫瑰花香、可可`
* **門市資訊**：`台南市中西區信義街 88 巷 12 號｜週三至週日 10:30–18:30（週一、二公休）`

## 🎨 視覺與 `DESIGN.md` 預設規範

* **氛圍關鍵字**：台南老宅木質調、編輯雜誌留白感、克制溫潤。
* **字體搭配**：標題 `Noto Serif TC` ＋ 內文 `Noto Sans TC`。

| Token 名稱 | Hex 色碼 | 語意用途 |
| :--- | :--- | :--- |
| `canvas` | `#FAF8F5` | 暖米白主背景 |
| `surface` | `#FFFFFF` | 商品與訂位卡片底色 |
| `surface_alt` | `#F2ECE4` | 故事段落交替暖底色 |
| `ink` | `#1E1B18` | 深焙咖啡墨色主文字 |
| `muted` | `#6B655E` | 次要風味描述與時間文字 |
| `primary` | `#8B5E3C` | 木質棕主 CTA 按鈕 |
| `hairline` | `#E5DFD7` | 1px 細邊框與分隔線 |

> [!WARNING]
> **AI 壞習慣禁令**：禁止使用純黑 `#000000`、禁止在暖咖色系裡突然出現預設亮藍色（`#3B82F6`）或紫色漸層按鈕；確保 375px 手機版按鈕高度至少 `44px`。

## 🤖 AI 全流程控制 Prompt 模板

### Prompt A：一鍵生成可互動單頁原型（適用於 Claude Design / Google Stitch / Antigravity）
```text
請讀取本份需求規格文件，為台南老宅精品咖啡館「木日 Kibi」製作「開店一週年限定活動」單頁 Landing Page（單一 HTML 檔，可使用 Tailwind CSS CDN）。

要求：
1. 嚴格套用文件內的「真實感繁體中文文案」與「色彩 Tokens（#FAF8F5 / #1E1B18 / #8B5E3C）」，引入 Google Fonts 的 Noto Serif TC 與 Noto Sans TC。
2. 完整實作「右側滑出式訂位抽屜（Slide-over Drawer）」互動：點擊頁面中任何「立即訂位」按鈕時，平滑滑出訂位面板，可選擇日期、時段（11:00 / 13:30 / 15:30）、人數，送出後顯示「預約成功編號與注意事項」確認畫面，並可點擊關閉。
3. 3 欄限定單品卡在手機版（375px）自動收合為單欄，且文字不裁切。
```

### Prompt B：透過 MCP 在 Figma / pen.dev 建立畫布與局部精修
```text
請先讀取本範例規格，透過 MCP（Figma use_figma 或 pencil execute）建立「Home - Desktop (1440px)」與「Home - Mobile (375px)」兩張畫框：
1. 依顏色規範建立 Color Variables，所有按鈕與卡片皆套用 Auto Layout（禁止使用固定絕對座標）。
2. 首屏 Hero 左側放主標語與雙按鈕（Primary「立即訂位」+ Secondary「探索限定豆」），右側放週年日期與圖片佔位框。
3. 完成後請截圖檢查，確認兩顆按鈕的視覺權重分明且無文字溢位。
```

## ✅ 成果驗收檢核清單

- [ ] 首屏 3 秒內能否清楚看見品牌名「木日 Kibi」、活動日期與「立即訂位」主按鈕？
- [ ] 點擊「立即訂位」是否以頁內滑出抽屜（Drawer）運作，而非死連結或跳離頁面？
- [ ] 兩顆按鈕的視覺權重是否清楚區分（主 CTA 實心填色，次要動作外框或文字連結）？
- [ ] 全頁色彩過渡是否一致（有無突然出現灰白或冷藍色跳色斷裂）？
- [ ] 切換至 `375px` 手機寬度檢查，卡片與抽屜表單是否皆可單手輕鬆點擊？
