**Landing Page（單頁行銷／活動轉換頁）** 的核心任務非常明確：**在單一頁面的捲動節奏中建立信任感與渴望，並引導訪客完成唯一的主要行動（CTA）**——例如訂位、註冊試用、購票或早鳥預購。

---

## 💡 用 AI 實作 Landing Page 的標準流程

1. **備妥雙合約檔案**：從下方挑選一個範例，先將內附的 **`PRD.md`** 與你挑選的其中一款風格 **`DESIGN.md`**（每題皆提供 3 種風格）複製進專案資料夾。
2. **依「注意事項」自己寫 Prompt**：先照著各題列出的注意事項逐條自己下指令（寫完再打開 `<details>` 裡的參考 Prompt 對照），訓練精準指揮 AI 的能力。
3. **演練「提案後修改」**：完成初版後，實際跑一次「階段二提案修改情境」，體會「先改 `PRD.md` / `DESIGN.md`、再改畫面」的穩定協作節奏。
