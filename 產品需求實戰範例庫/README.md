# 產品需求實戰範例庫：挑一個題目，用 AI 做出真實作品 📋

動手實作 UI/UX 原型時，學員最常遇到的問題不是「不會操作 AI 工具」，而是**「題目與需求太模糊」**。由於本課程**全程透過 AI 與 MCP 控制設計與產出**，你給 AI 的產品需求脈絡（Design Brief）越精準，產出的設計就越專業。

本範例庫依介面類型拆分為 **三大類別資料夾**，收錄 **12 個獨立且完整的繁體中文實戰範例檔**。每個獨立 `.md` 檔案都可直接作為 `@檔案` 脈絡餵給 AI（如在 Antigravity 直接 `@01_木日Kibi_台南老宅咖啡一週年活動頁.md`），裡面已預先整理好：

> [!TIP]
> **每個獨立範例檔都包含五大完整模組**
> 1. **📋 專案基本定位表**：介面類型、目標受眾、核心轉換指標、推薦 AI 工具。
> 2. **🎯 產品需求規格（PRD & 真實感文案素材）**：背景痛點、頁面架構與現成中文假資料（菜單、價格、議程、訂閱明細等）。
> 3. **🎨 視覺與 `DESIGN.md` 預設規範**：氛圍關鍵字、推薦 Hex 色彩 Tokens、繁體中文字體搭配與 AI 壞習慣禁令。
> 4. **🤖 AI 全流程控制 Prompt 模板**：包含 **Prompt A（一鍵生成完整互動原型）** 與 **Prompt B（Figma / pen.dev MCP 畫布控制與局部精修指令）**。
> 5. **✅ 成果驗收檢核清單**：讓你知道怎麼用產品與 UX 眼光檢查 AI 的成果。

## 🔄 如何使用這套獨立範例庫？（AI 全流程實戰步驟）

1. **直接打開一個獨立範例檔**：點進上方任一題目，例如 `01_木日Kibi_台南老宅咖啡一週年活動頁.md`。
2. **先找視覺靈感與試做多風格（可選）**：到 [建立自己的 `DESIGN.md` 與創意發想](../建立自己的DESIGN_md/02_參考靈感網站與建立多種設計風格.md) 找 1～2 張喜歡的參考截圖並生成多種風格比稿。
3. **把範例檔直接餵給 AI**：
   * 在 **Antigravity**：直接輸入 `@產品需求實戰範例庫/01_Landing_Page單頁行銷與活動頁/01_木日Kibi_台南老宅咖啡一週年活動頁.md`，接著貼上裡面的 **Prompt A** 或 **Prompt B**！
   * 在 **Claude Design / Google Stitch / pen.dev**：複製該檔案內的產品需求規格與 Prompt，直接開始生成並透過 MCP 或畫布控制細節。
4. **依驗收清單檢查**：完成後逐一勾選檔尾的「成果驗收檢核清單」，不滿意就下令局部修改，直到達標！
