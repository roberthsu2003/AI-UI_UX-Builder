## 🎯 產品需求規格（PRD & 資訊架構）

### 1. 專案背景與痛點
面對歐盟 CBAM 碳關稅與國內碳費法規，台灣製造業主管迫切需要專業輔導，但卻常被市面上「寫滿空泛口號、用廉價大樹與地球圖庫裝飾」的網站勸退。本網站必須展現**嚴謹、量化、值得高額企業委託**的 B2B 專業度。

### 2. 全站導覽與頁面架構（必備兩大視圖切換）
* **全站固定頁首與頁尾**：Logo `澄境永續 Clarity ESG`、導覽項目（顧問服務、產業案例、洞見白皮書、關於澄境）、右側「預約免費診斷」按鈕。
* **視圖一【企業首頁】**：
  1. **權威商務首屏（Hero）**：清晰傳達「從法規合規到供應鏈競爭力」，搭配雙按鈕（「預約 30 分鐘初步診斷」Primary ＋「瀏覽產業成功案例」Secondary）。
  2. **量化實績指標列（3 欄）**：用大字等寬數字呈現顧問實績（已輔導企業數、第三方查證通過率、平均節省盤查人時）。
  3. **四大核心服務矩陣**：ISO 14064-1 溫室氣體盤查、ISO 14067 產品碳足跡、GRI / SASB 永續報告書、供應鏈減碳轉型輔導（每張卡清楚列出「適用對象」與「最終交付物」）。
* **視圖二【產業案例與白皮書資源頁】**：
  1. **麵包屑導覽**：`首頁 > 產業案例與洞見資源`。
  2. **產業別篩選標籤**：全部、電子零組件、精密機械、食品冷鏈，即時篩選下方案例卡片。
  3. **結構化案例卡片**：每張必須採三段式結構「`導入前痛點` → `澄境解法` → `量化成果`」。
  4. **白皮書索取轉換表單**：雙欄轉換區（左側介紹手冊章節，右側輸入「公司名稱、職稱、企業信箱」送出後即時解鎖《2026 台灣製造業碳盤查實戰手冊 PDF》模擬下載按鈕）。

### 3. 真實感繁體中文文案與預設素材（直接給 AI 使用）
* **主標語**：`讓淨零合規，成為台灣製造業的下一道競爭護城河。`
* **3 組量化指標**：`180+ 家｜累計輔導台灣製造與科技企業`、`100%｜協助取得第三方查證聲明書`、`35%｜透過數位工具平均節省盤查人時`
* **3 筆產業案例**：
  1. `電子零組件｜桃園某 PCB 印刷電路板廠` — 痛點：`外銷歐美客戶要求提供單片板材碳足跡數據，廠內無專職人員` → 解法：`建立製程用電邊界並導入自動化盤查表單` → 成果：`3 個月通過查證，順利保住歐洲 Tier-1 訂單，並找出高耗能烘烤段節電 11%`。
  2. `精密機械｜台中某 CNC 工具機製造商` — 痛點：`上下游供應商逾 40 家，排放係數收集零散耗時` → 解法：`設計標準化供應商數據填報平台與稽核輔導` → 成果：`盤查彙整時間由 4 個月縮短至 5 週`。
  3. `食品冷鏈｜南部某生鮮物流倉儲集團` — 痛點：`冷凍機組冷媒逸散與車隊柴油碳排難以追蹤` → 解法：`盤點範疇一移動與逸散排放源，制定設備汰換投資回收期模型` → 成果：`首年減少 14% 範疇一排放量，同步降低電費支出`。

## 🎨 視覺與 `DESIGN.md` 預設規範

* **氛圍關鍵字**：高端管理顧問感（McKinsey / BCG 數位化質感）、冷靜嚴謹、結構化數據。
* **字體搭配**：`Noto Sans TC` + `Inter` + 數據指標使用 `JetBrains Mono`。

| Token 名稱 | Hex 色碼 | 語意用途 |
| :--- | :--- | :--- |
| `canvas` | `#F8FAFB` | 極簡冷白主背景 |
| `surface` | `#FFFFFF` | 服務與案例卡片底色 |
| `ink` | `#0F1E22` | 深墨綠炭黑主文字 |
| `muted` | `#4A5C61` | 副標與說明文字 |
| `primary` | `#0E2A2F` | 沉穩深海墨綠主色與按鈕 |
| `accent` | `#B88E4A` | 霧面青銅金點綴強調線與數據標記 |
| `hairline` | `#DCE3E5` | 1px 細框線 |

> [!WARNING]
> **AI 壞習慣禁令**：**絕對禁止**使用常見的螢光草綠或大樹／地球向量插畫；禁止把 B2B 官網做得像購物網站，表格與條列要俐落對齊。

## 🤖 AI 全流程控制 Prompt 模板

### Prompt A：一鍵生成可切換首頁與案例資源頁的網站原型
```text
請讀取本份規格文件，為「澄境永續顧問 Clarity ESG」設計極具高端商務信任感的 B2B 企業官網原型（單一 HTML 檔，可使用 Tailwind CSS CDN，包含「企業首頁」與「產業案例及白皮書頁」兩個視圖切換）。

要求：
1. 完整使用文件內的「3 組量化指標、四大服務矩陣與 3 筆詳細產業成功案例」。
2. 【首頁視圖】：包含權威 Hero 區、3 欄等寬數據實績列、2x2 整齊的四大服務矩陣卡片（列出適用對象與交付文件）。
3. 【案例與資源視圖】：包含麵包屑導覽、產業分類篩選按鈕（全部/電子零組件/精密機械/食品冷鏈），每張案例清楚呈現「痛點 → 解法 → 量化成果」三段結構；下方實作「《2026 碳盤查實戰白皮書》索取表單」，填寫公司名與 Email 送出後即時切換成已解鎖下載連結畫面。
4. 嚴格使用高階顧問冷靜配色（#F8FAFB / #0E2A2F / #B88E4A），禁止使用廉價亮綠色或大樹插畫。
```

### Prompt B：透過 MCP 在 Figma / pen.dev 建立畫布與局部精修
```text
請讀取本範例規格，透過 MCP 在畫布上建立「澄境永續顧問」的 B2B 首頁畫框（1440px）：
1. 頂部設定固定導覽列，Hero 區左側排版標題與雙按鈕，右側以簡約幾何數據卡呈現「180+ 家輔導實績」。
2. 服務矩陣採用 2x2 Auto Layout 格狀卡片，框線使用 1px #DCE3E5 細線，不加過重陰影。
3. 完成後截圖檢查，確認商務文字層級分明且數字採用等寬字體對齊。
```
