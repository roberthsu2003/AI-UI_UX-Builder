**多頁式網站（Multi-page Website / Web Portal）** 承載更複雜的資訊架構與分眾需求。這類題目非常考驗你能否用 `PRD.md` 鎖定導覽階層、用 `DESIGN.md` 鎖定全站一致性，確保 AI 做出來的多頁或雙視圖原型**不會讓使用者迷路**（對照 [網站架構觀念](../../網站架構觀念/README.md)）。

---

## 💡 用 AI 實作多頁式網站的標準流程

1. **複製 `PRD.md` ＋ 選一款 `DESIGN.md`**：每題皆提供 3 種不同設計調性的 `DESIGN.md`，建議先選一種完成初版，甚至可拿另外兩種來做「提案風格重繪」比較。
2. **守住導覽一致與位置感**：寫 Prompt 時務必逐條檢查注意事項，確認有要求 AI 保持 Header/Footer 一致，並在內頁放入 **麵包屑導覽** 與 **區域導覽列**。
3. **演練「提案後修改」**：完成初版後，依據階段二模擬業主回饋，先同步更新 `PRD.md` 與 `DESIGN.md`（記下 `Changelog`）再修改網頁。
