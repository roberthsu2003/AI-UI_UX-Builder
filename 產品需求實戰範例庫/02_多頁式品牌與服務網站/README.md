**多頁式網站（Multi-page Website / Web Portal）** 承載更複雜的資訊架構與分眾需求。與單頁不同，這類作品在用 AI 控制設計時，必須特別要求 AI 守住 [網站架構觀念](../../網站架構觀念/README.md) 的核心規則——**絕對不能讓使用者迷路**。

---

## 💡 用 AI 設計多頁式網站的三大控制重點

1. **全站導覽一致性（Header & Footer 固定）**：在 Prompt 中明確要求 AI 讓全域導覽列在所有視圖／頁面中維持完全相同的位置、項目順序與高度。
2. **位置提示元素（麵包屑 ＋ 區域導覽）**：所有二、三層內頁必須包含 **麵包屑導覽（Breadcrumbs）** 與清楚的 **左側／上方區域導覽列**，讓使用者隨時知道自己在哪裡。
3. **單一 HTML 多視圖模擬技巧**：為了方便在課堂直接於瀏覽器演示多頁跳轉，可要求 AI 在同一個單一原型中實作「視圖切換（如首頁 ↔ 列表頁 ↔ 詳情內頁）」，或用 `pen.dev` / `Figma` 平行產出多張畫框。
