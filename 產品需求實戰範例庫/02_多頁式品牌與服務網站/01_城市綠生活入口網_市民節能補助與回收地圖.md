## 🎯 產品需求規格（PRD & 資訊架構）

### 1. 專案背景與痛點
傳統公部門入口網站常面臨「首頁擠滿廣告跑馬燈、重要申辦按鈕藏在三層選單後、法條寫得像文言文」的痛點。本專案目標是建立一個**以使用者任務為中心、符合 WCAG 無障礙標準**的多頁式公共服務網站。

### 2. 全站導覽與頁面架構（必備兩大視圖切換）
* **全站固定頁首與頁尾**：
  * 全域導覽列（Global Navbar）：Logo `城市綠生活入口網`、三大分眾入口（`節能補助`、`回收地圖`、`綠生活活動`）、站內搜尋欄、「申請進度查詢」按鈕。
* **視圖一【首頁】**：
  1. **任務搜尋＋四大高頻捷徑卡**：冷氣／冰箱汰舊換新補助、電動機車補助、大型廢棄物清運預約、資源回收站點查詢。
  2. **互動式「補助資格試算器」**：勾選「是否為住宅用電戶」、選擇「汰換品項（一級能效冷氣 / 冰箱）」與「是否搭配舊機回收」，即時算出一目了然的預估補助金額，並顯示「前往申請此補助」按鈕（點擊直接切換至視圖二）。
  3. **精簡最新公告區**：分類膠囊標籤＋清楚日期標題（最多顯示 4 筆，不放雜亂表格）。
* **視圖二【住宅家電補助申辦內頁】**（重點練習防迷路架構）：
  1. **麵包屑導覽**：`首頁 > 家庭節能補助 > 住宅家電汰舊換新補助`。
  2. **雙欄佈局（25% / 75%）**：左側為垂直「區域導覽列」（切換錨點／段落：`申請資格`、`應備文件清單`、`線上申請步驟`、`常見問題`）；右側為主要內容區，用 `Step 1 → Step 2 → Step 3` 卡片與「可勾選的文件準備清單（Checklist）」取代冗長文字。

### 3. 真實感繁體中文文案與預設素材（直接給 AI 使用）
* **補助試算邏輯（模擬）**：
  * `一級能效冷氣汰舊換新`：政府補助 `NT$ 3,000`（若勾選「配合舊機廢四機回收聯單」＋ 貨物稅減免試算再加 `NT$ 2,000` ＝ 最高 `NT$ 5,000`）
  * `一級能效電冰箱汰舊換新`：政府補助 `NT$ 3,000`（加計減免最高 `NT$ 5,000`）
* **應備文件清單（可勾選確認）**：`1. 申請人身分證正反面影本`、`2. 購買一級能效家電之統一發票（需載明型號）`、`3. 廢四機回收聯單第三聯`、`4. 申請人存摺封面影本`、`5. 裝機地址最新一期電費單`。
* **最新公告 3 則**：`2026 年度住宅家電汰舊換新補助受理至 12/31 止`、`全市新增 18 處智慧電池回收機據點`、`11 月二手物交換市集活動報名開放`。

## 🎨 視覺與 `DESIGN.md` 預設規範

* **氛圍關鍵字**：清新信任感、市政無障礙親和力、資訊極度清晰。
* **字體搭配**：`Noto Sans TC`（內文字級**嚴格不小於 `16px`**，行高 `1.65`）。

| Token 名稱 | Hex 色碼 | 語意用途 |
| :--- | :--- | :--- |
| `canvas` | `#F7F9F7` | 清爽微綠白底色 |
| `surface` | `#FFFFFF` | 卡片與試算器底色 |
| `ink` | `#1F2937` | 高對比深炭灰文字（符合 WCAG AA） |
| `muted` | `#4B5563` | 輔助說明文字 |
| `primary` | `#1B5E3A` | 穩重森綠主色與按鈕 |
| `accent` | `#E6F4EC` | 選中狀態與重點提示淺綠底色 |
| `hairline` | `#D1DBD5` | 1px 分隔線與表格邊框 |

> [!WARNING]
> **AI 壞習慣禁令**：禁止使用極細淺灰字（如 `#9CA3AF` 配白底，長輩看不清楚）；所有狀態提醒除了顏色外，必須同時附上圖示或文字標籤（不可只靠顏色辨識）。

## 🤖 AI 全流程控制 Prompt 模板

### Prompt A：一鍵生成可切換多視圖網站原型
```text
請讀取本份規格文件，為市政便民網站「城市綠生活入口網」製作多頁式網站原型（單一 HTML 檔，可使用 Tailwind CSS CDN，並實作「首頁」與「住宅家電補助申辦內頁」兩個視圖切換）。

要求：
1. 全域導覽列（Header）與頁尾（Footer）在兩個視圖間必須固定且完全一致。
2. 【首頁視圖】：包含搜尋框、4 張高頻服務捷徑卡，以及可即時互動的「補助資格試算器」（依品項與勾選項目動態計算 NT$ 補助金額），點擊「前往申請此補助」可直接跳轉至內頁視圖。
3. 【補助申辦內頁視圖】：必須包含麵包屑導覽（首頁 > 家庭節能補助 > 住宅家電汰舊換新補助），以及「左側 25% 區域導覽列 + 右側 75% 主要步驟內容」雙欄排版，右側提供 5 項應備文件的互動式勾選清單（Checklist），全部勾選後才亮起「立即線上申辦」按鈕！
4. 嚴格遵守 WCAG 高對比配色（#F7F9F7 / #1F2937 / #1B5E3A）與至少 16px 內文字級。
```

### Prompt B：透過 MCP 在 Figma / pen.dev 建立雙視圖畫布
```text
請讀取本範例規格，透過 MCP 在畫布上並排建立兩張 1440px 桌機畫框：
1. `Page 01 - Home`：呈現固定 Header、搜尋＋4 張捷徑卡、補助試算器。
2. `Page 02 - Subsidy Detail`：呈現相同的固定 Header、麵包屑導覽列，以及「左側 25% 樹狀區域導覽 ＋ 右側 3 步驟申辦圖解」雙欄排版。
完成後請截圖檢查，確認兩頁的 Header 高度、Logo 位置與選單順序 100% 一致。
```

## ✅ 成果驗收檢核清單

- [ ] 首頁與申辦內頁的全域導覽列位置與項目順序是否 100% 固定一致？
- [ ] 補助內頁是否具備清楚的 **麵包屑導覽** 與 **左側區域導覽列**，讓使用者不會迷路？
- [ ] 首頁的補助試算器是否能隨選項切換即時加總金額並引導跳轉內頁？
- [ ] 內頁的應備文件是否做成可勾選的檢核清單（防呆引導）而非密密麻麻的文字段落？
- [ ] 正文文字大小是否至少 `16px` 且與背景具備高閱讀對比度（無淺灰字配白底）？
