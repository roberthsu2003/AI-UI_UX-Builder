| 項目 | 內容規格 |
| :--- | :--- |
| **主題名稱** | 《沐光美學牙醫診所》結合柔和空間感、透明療程與線上初診預約之診所官網 |
| **介面類型** | `多頁式網站（醫療服務形象網站，含首頁、療程專區與四步驟預約流程）` |

## 🎯 產品需求規格（PRD & 資訊架構）

### 1. 專案背景與痛點
多數傳統醫療診所網站不僅介面老舊，往往還直接放上血淋淋的牙科手術對比照，反而加劇患者看牙的恐懼；同時也常找不到確切休診時段與初診預約方式。本專案要打造「像精品空間一樣柔和安心、流程透明」的現代醫療網站。

### 2. 全站導覽與頁面架構（必備視圖切換 ＋ 四步驟預約 Modal）
* **全站固定頁首與頁尾**：Logo `沐光美學牙醫`、導覽（診所環境、專業療程、醫師團隊、門診時刻表）、右側醒目 CTA「線上初診預約」。
* **視圖一【診所首頁】**：
  1. **溫柔無壓首屏（Hero）**：傳達「溫柔對待每一次看診」理念，提供「線上初診預約」與「查看本週門診時間」按鈕。
  2. **四大安心承諾**：獨立隔音診間、術前書面透明報價單、數位 3D 口掃無痛取模、無壓力耐心溝通。
  3. **醫師團隊卡片（3 位）**：顯示醫師專長標籤與看診風格簡介（例如：`擅長兒童與怕痛患者溝通`）。
  4. **本週門診時段一覽表**：週一至週六早／午／晚診清楚標示（休診明確標註「休診」而非留白猜測）。
* **視圖二【專業療程介紹頁】**（練習區域導覽）：
  1. **麵包屑導覽**：`首頁 > 專業療程介紹 > 隱形矯正`。
  2. **左側垂直區域導覽列 ＋ 右側療程說明**：切換「隱形矯正、全瓷美學貼片、舒眠微創植牙、定期洗牙健檢」，每項包含「適合誰、療程 3 步驟、透明參考價格區間、術後須知」。
* **互動流程【四步驟無縫初診預約 Modal】**：
  * 點擊任何「線上初診預約」按鈕彈出覆蓋式視窗，上方顯示 `1 選項目 → 2 選時段 → 3 填資料 → 4 完成憑證` 進度條，一步一步引導完成預約並產出預約確認單。

### 3. 真實感繁體中文文案與預設素材（直接給 AI 使用）
* **主標語**：`把看牙醫變成一件不用緊張的事：溫柔傾聽，透明治療。`
* **醫師團隊 3 位**：
  1. `林沐晨 院長` — 台大牙醫學系｜專長：`全瓷美學貼片、數位前牙重建`（標籤：`細心傾聽需求`）
  2. `陳知夏 副院長` — 陽明交大齒顎矯正專科｜專長：`隱形牙套矯正、青少年咬合引導`（標籤：`溫柔不推銷`）
  3. `許柏翰 主治醫師` — 台北醫學大學牙醫學系｜專長：`舒眠微創植牙、無痛智齒拔除`（標籤：`專治看牙焦慮`）
* **療程參考透明價目**：
  * `數位隱形矯正`：`NT$ 140,000 – 220,000`（含 3D 口掃模擬與維持器）
  * `全瓷美學貼片（單顆）`：`NT$ 22,000 – 28,000`（超薄不傷真牙工藝）
  * `舒眠微創植牙（單顆）`：`NT$ 65,000 – 85,000`（含 3D 電腦斷層導引板）
  * `健保洗牙與全口健檢`：`依健保規定收費（僅掛號費 NT$ 200）`

## 🎨 視覺與 `DESIGN.md` 預設規範

* **氛圍關鍵字**：柔和療癒空間感、安心信任、無壓迫醫療美學。
* **字體搭配**：`Noto Sans TC`（標題可搭配 `Noto Serif TC` 增加人文溫度）。

| Token 名稱 | Hex 色碼 | 語意用途 |
| :--- | :--- | :--- |
| `canvas` | `#FBF9F6` | 溫暖柔白主背景 |
| `surface` | `#FFFFFF` | 卡片與預約彈窗底色 |
| `ink` | `#28302C` | 深橄欖灰主文字 |
| `muted` | `#5F6B65` | 學經歷與輔助說明文字 |
| `primary` | `#5B7B6D` | 安心鼠尾草綠主按鈕與選中進度條 |
| `accent` | `#EBF2EE` | 溫柔淺灰綠標籤底色 |
| `hairline` | `#E4E0D8` | 1px 細邊框 |

> [!WARNING]
> **AI 壞習慣禁令**：禁止使用高飽和警示紅、刺眼冷白 `#FFFFFF` 配深藍冰冷醫院風格；禁止使用誇張恐怖的牙齒寫實圖示。

## 🤖 AI 全流程控制 Prompt 模板

### Prompt A：一鍵生成可切換療程頁與四步驟預約流程的網站原型
```text
請讀取本份規格文件，為「沐光美學牙醫診所」設計柔和安心的醫療網站原型（單一 HTML 檔，可使用 Tailwind CSS CDN，支援「診所首頁」與「專業療程頁」切換，並實作「四步驟初診預約 Modal」）。

要求：
1. 完整納入文件內的「四大安心承諾、3 位醫師團隊、週一至週六門診時段表、四大療程詳細資料」。
2. 【視圖二：療程介紹頁】：包含麵包屑導覽，以及左側區域導覽列（點擊切換「隱形矯正 / 全瓷貼片 / 舒眠植牙 / 定期洗牙」，即時更新右側內容與透明參考費用）。
3. 【四步驟無縫預約 Modal】：點擊任一「線上初診預約」開啟彈窗，頂部顯示 1–4 步驟進度條：
   - Step 1：單選想預約的諮詢項目
   - Step 2：選擇看診日期與早/午/晚診時段（含醫師選擇）
   - Step 3：填寫姓名與手機號碼（基本驗證）
   - Step 4：生成完整的「預約成功確認憑證卡」（顯示預約編號、時間與看診提醒）
4. 嚴格遵守鼠尾草綠柔白配色（#FBF9F6 / #5B7B6D / #28302C）。
```

### Prompt B：透過 MCP 在 Figma / pen.dev 建立畫布與局部精修
```text
請讀取本範例規格，透過 MCP 在畫布上建立「療程介紹內頁（1440px）」與「四步驟預約 Modal 視窗」：
1. 療程內頁左側設定 260px 區域導覽欄，右側顯示「適合對象、3 步驟圖解、透明費用方塊」並套用鼠尾草綠柔和風格。
2. 預約 Modal 寬度 560px、圓角 16px，頂部清楚繪製 Step 1 到 Step 4 的步驟指示器（Stepper）。
3. 完成後截圖檢查，確認門診表與步驟條排版對齊且無壓迫感。
```
