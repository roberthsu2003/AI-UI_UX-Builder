| 項目 | 內容規格 |

| **主題名稱** | 《島嶼慢行 Island Slow》主打 6 人以下台灣在地文化、山林步道與手作體驗預約平台 |

## 🎯 產品需求規格（PRD & 資訊架構）

### 1. 專案背景與痛點
大型旅遊電商網站往往充斥紅底黃字促銷標籤與雜亂彈窗，讓人感受不到旅行的美好。本專案希望結合「旅遊雜誌的寧靜美學」與「電商級的高效篩選與 Sticky 試算預約」，提供無壓迫感的預約體驗。

### 2. 全站導覽與頁面架構（必備兩大視圖切換）
* **全站固定頁首與頁尾**：Logo `島嶼慢行 Island Slow`、導覽項目（探索行程、領隊故事、企業包團、我的收藏）。
* **視圖一【行程探索列表頁】**：
  1. 柔和首屏標題與**多條件互動篩選列**：支援依「地區（全部／花東／中台灣／南台灣）」與「主題標籤（全部／山林步道／部落文化／工藝手作）」即時交集篩選下方行程。
  2. **3 欄格狀行程卡片（共 6 筆真實感行程）**：每張卡片顯示封面佔位圖、地區與天數膠囊標籤、行程名稱、成團人數限制（如 `限 6 人`）與每人價格；點擊任一卡片進入詳情頁。
* **視圖二【單一行程詳情頁】**：
  1. **麵包屑導覽**：`首頁 > 探索行程 > 花東地區 > 太魯閣砂卡礑部落食器手作二日行`（含「返回行程列表」按鈕）。
  2. **雙欄不對稱佈局（65% / 35%）**：
     * 左欄（65%）：行程核心亮點、在地領隊介紹、Day 1 與 Day 2 詳細時間軸、費用包含與不包含明細。
     * 右欄（35% **Sticky 隨捲動固定預約卡**）：選擇出發梯次下拉選單、報名人數 `+ / -` 按鈕、即時總價試算與「立即預約名額」按鈕（送出後顯示預約保留確認）。

### 3. 真實感繁體中文文案與預設素材（直接給 AI 使用）
* **6 筆深度行程清單**：
  1. `太魯閣砂卡礑・部落食器手作二日行`｜花東｜二日慢旅｜部落文化｜限 6 人｜`NT$ 6,800`
  2. `阿里山特富野・古道雲海晨走一日行`｜中台灣｜一日體驗｜山林步道｜限 8 人｜`NT$ 2,900`
  3. `台東長濱・太平洋月光陶藝與海鹽採集`｜花東｜二日慢旅｜工藝手作｜限 6 人｜`NT$ 7,200`
  4. `屏東霧台・魯凱石板屋與小米酒釀造`｜南台灣｜一日體驗｜部落文化｜限 6 人｜`NT$ 3,400`
  5. `南投合歡溪・原始鐵杉林秘境野餐`｜中台灣｜一日體驗｜山林步道｜限 6 人｜`NT$ 3,100`
  6. `台南漁光島・海廢木質藍染創作工作坊`｜南台灣｜一日體驗｜工藝手作｜限 8 人｜`NT$ 2,200`

## 🎨 視覺與 `DESIGN.md` 預設規範

* **氛圍關鍵字**：山海大地色系、靜謐旅行誌、無壓迫留白。
* **字體搭配**：標題 `Noto Serif TC` ＋ 內文 `Noto Sans TC`。

| Token 名稱 | Hex 色碼 | 語意用途 |
| :--- | :--- | :--- |
| `canvas` | `#F7F5F0` | 米砂色主背景 |
| `surface` | `#FFFFFF` | 行程卡與右側預約卡底色 |
| `ink` | `#232B26` | 深林石板主文字 |
| `muted` | `#646D67` | 次要地點、天數說明 |
| `primary` | `#2C4037` | 深石板綠主要按鈕與高亮篩選狀態 |
| `accent` | `#B86B4B` | 陶土暖棕標籤與重點強調色 |
| `hairline` | `#E3DFD6` | 1px 細框線 |

> [!WARNING]
> **AI 壞習慣禁令**：禁止出現「限時搶購！最後1小時！」的紅色閃爍倒數標籤或滿滿的促銷徽章；詳情頁右側 Sticky 預約卡在手機版（375px）應改為自然流式區塊或底部固定條，避免擋住左側時間軸閱讀。

## 🤖 AI 全流程控制 Prompt 模板

### Prompt A：一鍵生成可切換列表與詳情的網站原型
```text
請讀取本份規格文件，為深度旅遊預約平台「島嶼慢行 Island Slow」製作多頁式網站原型（單一 HTML 檔，可使用 Tailwind CSS CDN，支援「行程探索列表頁」與「單一行程詳情頁」切換）。

要求：
1. 內建文件提供的全部 6 筆台灣行程真實感資料。
2. 【視圖一：探索列表頁】實作多條件即時篩選：點擊「地區（全部/花東/中台灣/南台灣）」與「主題（全部/山林步道/部落文化/工藝手作）」按鈕時，下方 3 欄格狀卡片即時過濾更新，若無符合結果須顯示友善空狀態提示。
3. 【視圖二：行程詳情頁】點擊任一卡片進入（並同步帶入該行程的標題、地區與單價！）：
   - 頂部顯示麵包屑導覽與返回列表按鈕。
   - 左側（65%）顯示亮點摘要、領隊卡片與 Day 1/Day 2 時間軸；右側（35%）實作 Sticky 預約試算卡，支援梯次選擇、人數 `+ / -` 按鈕與即時總金額計算，按下「立即預約名額」顯示預約保留確認狀態。
4. 嚴格使用大地自然配色（#F7F5F0 / #2C4037 / #B86B4B）。
```

### Prompt B：透過 MCP 在 Figma / pen.dev 建立畫布與局部精修
```text
請讀取本範例規格，透過 MCP 在畫布上建立兩張 1440px 桌機畫框：
1. `01_Explore_List`：含全域導覽、篩選膠囊列、以及 3 欄 2 列共 6 張結構統一的行程卡片。
2. `02_Trip_Detail`：含麵包屑導覽、左側 65% 時間軸區塊與右側 35% 預約計算卡片。
完成後截圖檢查，確保卡片圖片比例統一（16:10）且標題不因長度不同導致卡片高度不齊。
```

## ✅ 成果驗收檢核清單

- [ ] 探索頁的「地區」與「主題」篩選條件能否正確交集過濾出對應卡片？
- [ ] 點擊不同行程卡片進入詳情頁時，右側單價與麵包屑標題是否會動態帶入該筆行程？
- [ ] 詳情頁右側預約卡調整人數（`+ / -`）時，總金額是否正確連動計算？
- [ ] 視覺是否維持雜誌般的寬裕留白，沒有廉價旅遊網的紅黃閃爍促銷標籤？
- [ ] 手機版（`375px`）瀏覽詳情頁時，右側預約卡是否正確收合流暢，未遮擋主內容？
