當介面從「閱讀與瀏覽資訊」進化到「高頻率操作與管理數據」時，設計重點就會轉向 **應用程式（Web App / Mobile Web App / Dashboard）**。這類題目適合練習 [無縫式介面](../網站架構觀念/無縫式介面/README.md)（覆蓋式彈窗、底部滑出抽屜、不換頁即時更新）、表單防呆以及資訊密度控制。

## 範例 09：《好食光 QR Order》餐廳手機掃碼點餐與客製化系統

* **主題**：《好食光 QR Order》內用桌邊掃碼點餐、客製化配料與即時分帳結帳介面
* **介面**：`互動應用程式（Mobile Web App，建議以手機視角 390px 為主設計）`
* **產品需求**：
  * **專案背景與目標受眾**：餐廳尖峰時段人力吃緊，客人用手機掃碼點餐最怕「一直換頁載入很慢、加點配料按錯、不知道到底送出訂單沒」。本系統追求單手拇指好操作、零跳轉的點餐體驗。
  * **核心功能與無縫互動需求**：
    1. **頂部桌號識別與置頂分類導覽**：清楚顯示「目前桌號：A05・內用 2 位」，下方提供可橫向滑動的分類頁籤（主廚推薦、經典飯麵、小菜炸物、手作飲品）。
    2. **餐點列表與快速加入**：每道菜顯示照片佔位、價格與過敏原／辣度小標籤。
    3. **客製化 Bottom Sheet（底部滑出抽屜）**：點擊餐點後，由螢幕底部滑出客製化面板（選擇辣度／甜度冰塊、加購配料複選框、備註欄、數量加減與「加入購物車 NT$ xxx」按鈕）。
    4. **底部常駐購物車條與訂單確認抽屜**：底部固定顯示「購物車（共 3 件）｜小計 NT$ 540｜查看明細」。點擊展開明細抽屜，可調整數量、移除品項並按下「送出訂單至廚房」，送出後顯示出餐進度狀態。
  * **UI/UX 與操作要求**：所有按鈕與列表高度符合拇指點擊舒適度（至少 `44px`），即時計算小計不可出錯。

<details>
<summary>📋 點此展開：可直接複製給 AI 的啟動 Prompt</summary>

```text
請為餐廳內用系統「好食光 QR Order」設計一個專注於單手操作、流暢無跳轉的 Mobile Web App 點餐介面（單一 HTML 檔，請在電腦版瀏覽器中置中模擬 390px 手機外框展示，手機版則滿版顯示）。

【核心互動與功能規格】
1. 頂部資訊列：顯示餐廳名稱「好食光食堂」、顯眼的「桌號 A05」膠囊標籤，以及「已送出訂單紀錄」按鈕。
2. 置頂分類切換列（Sticky Tabs）：橫向導覽「主廚招牌、暖心飯麵、台味小菜、手作茶飲」，點擊可切換或平滑捲動至對應分類。
3. 菜單列表（至少 8 道真實感台灣餐點）：包含菜名、簡短介紹、售價、辣度／人氣標籤與「+ 選擇」按鈕。
4. 客製化底部抽屜（Bottom Sheet — 必備互動）：
   - 點擊任一餐點時，從底部平滑滑出客製化面板（含背景半透明遮罩）。
   - 依餐點屬性提供選項：例如「份量（正常 / 加大 +$30）」、「加料區（溏心蛋 +$25、起司 +$20）」、「辣度／甜度單選」、備註框與數量調整，即時顯示此筆小計並加入購物車。
5. 底部常駐購物車列 ＋ 結帳明細抽屜：
   - 購物車有商品時，底部顯示「共 X 樣｜NT$ XXX｜確認點餐」浮動條。
   - 點擊後展開明細抽屜，可加減數量、清空或按下「送出至廚房」，送出後切換成「廚房已接單・準備中」的安心確認畫面。

【視覺規範】
- 暖白底色（#FAFAFA）搭開胃暖橘紅主色（#E0522C）與清晰深墨文字（#1E1E1E）。
- 所有按鈕高度至少 44px，價格數字使用等寬對齊，視覺俐落好讀。
```

## 範例 10：《SubTrack 訂閱管家》個人每月扣款追蹤儀表板

* **主題**：《SubTrack 訂閱管家》集中追蹤 Netflix、Spotify、AI 工具與雲端服務扣款的個人財務管理面板
* **介面**：`互動應用程式（Web App Dashboard，桌面與響應式網頁應用）`
* **產品需求**：
  * **專案背景與目標受眾**：現代人同時訂閱了影音串流、AI 工具（ChatGPT/Claude/Figma）、雲端硬碟與健身房，常忘記扣款日期而白白多付錢。目標是讓使用者一眼看清「每個月固定流出多少錢」與「下週誰要扣款」。
  * **核心功能與無縫互動需求**：
    1. **頂部 KPI 摘要卡（3 張）**：本月固定總支出（NT$）、有效訂閱數量、未來 7 天內即將扣款總額。
    2. **資料視覺化圖表**：使用 Chart.js（或 SVG 圓餅/長條圖）呈現各類別佔比（影音娛樂、AI 生產力、雲端儲存、生活服務）。
    3. **訂閱項目管理清單**：支援依類別篩選（全部／影音／工作／生活）與切換「年繳換算月均 / 原始週期顯示」，每列顯示服務名稱、下一次扣款日、距離天數倒數標籤（如 `3 天後扣款` 警示）與開關／刪除操作。
    4. **「新增訂閱」彈出視窗（Modal）**：點擊右上角 `+ 新增訂閱` 開啟表單，輸入名稱、金額、幣別（TWD/USD 自動約略換算）、扣款週期（月／年）與分類，送出後即時新增至清單並更新上方總支出與圖表！
  * **UI/UX 與操作要求**：數據層級清晰、數字對齊好掃描，支援深色／淺色切換（或精緻深色儀表板風格）。

<details>
<summary>📋 點此展開：可直接複製給 AI 的啟動 Prompt</summary>

```text
請為個人財務工具「SubTrack 訂閱管家」設計一個功能完整、可實際互動的 Web App 儀表板原型（單一 HTML 檔，可引入 Chart.js CDN 繪製圖表）。

【核心功能與互動規格】
1. 頂部工具列：品牌 Logo「SubTrack」、深淺模式切換開關（選配）、醒目的「+ 新增訂閱」主要按鈕。
2. 總覽 KPI 卡片（3 欄）：
   - 「本月預估總支出」（會隨下方新增／刪除訂閱項目即時重新加總更新！）
   - 「目前訂閱數量」（例如：7 項有效服務）
   - 「7 日內即將扣款」（突顯近期要扣款的金額與項目數）
3. 雙欄分析區：
   - 左側：使用 Chart.js 繪製「各分類支出佔比」環圈圖（Doughnut Chart），包含 AI 工具、影音串流、雲端軟體、生活會員。
   - 右側：「即將扣款提醒時間軸」，列出最近 3 筆即將扣款的服務與倒數天數警告標籤。
4. 訂閱明細列表與篩選：
   - 提供分類篩選按鈕（全部、AI 生產力、影音娛樂、雲端與生活）與關鍵字搜尋框。
   - 預設內建 6 筆貼近台灣使用者的訂閱資料（如 Claude Pro、Netflix、Spotify、iCloud+、YouTube Premium、Figma）。
   - 每列支援「刪除」按鈕，刪除後上方 KPI 與圖表同步更新。
5. 新增訂閱 Modal（必備互動）：
   - 點擊「+ 新增訂閱」開啟 Modal 表單（服務名稱、分類、金額、扣款週期：每月/每年、下次扣款日），按下儲存後直接寫入畫面狀態。

【視覺規範】
- 採用高質感專業 Fintech 淺灰白（#F8FAFC）或深曜石黑（#0F172A）儀表板風格，卡片邊界使用 1px 細線區隔，數字建議使用等寬字體（tabular-nums）確保垂直對齊。
```

</details>

## 範例 11：《GreenPulse 綠脈動》商辦大樓即時用電與碳排監控後台

* **主題**：《GreenPulse 綠脈動》企業總部與商辦大樓即時用電、空調負載與異常警示監控系統
* **介面**：`互動應用程式（B2B 企業級數據監控後台 Web App）`
* **產品需求**：
  * **專案背景與目標受眾**：企業廠務人員、總務與永續管理師需要每天盯著各樓層用電異常，並在月底匯出用電碳排報告。重點在於「不擁擠但資訊密度高」，異常紅燈一眼可見。
  * **核心功能與無縫互動需求**：
    1. **固定左側垂直導覽列**：切換「即時戰情總覽、樓層用電明細、異常警示紀錄、碳排月報匯出」（實作上可切換視圖或高亮狀態）。
    2. **時間維度無縫切換器**：頂部提供 `今日即時 / 本週趨勢 / 本月累計` 切換，切換時下方數據卡與趨勢圖隨之變化。
    3. **即時趨勢折線圖＋尖離峰用電分析**：對比實際用電曲線與警戒上限虛線。
    4. **各樓層狀態監控表**：列出 1F 大廳、3F 研發中心、5F 機房等用電度數（kWh）、空調佔比與狀態標籤（`正常運作` / `尖峰超標警告`），點擊警示列可展開右側異常診斷建議抽屜。
  * **UI/UX 與操作要求**：嚴格遵守「狀態顏色規範」（正常綠、警告琥珀、超標紅，且必搭文字/Icon），不可濫用大紅大綠造成視覺疲勞。

<details>
<summary>📋 點此展開：可直接複製給 AI 的啟動 Prompt</summary>

```text
請為企業能源管理平台「GreenPulse 綠脈動」設計一個高專業度的 B2B 數據監控後台（Dashboard Web App，單一 HTML 檔，可使用 Chart.js CDN）。

【介面與功能規格】
1. 整體後台骨架：
   - 左側固定垂直導覽列（寬 240px，手機版可收合）：Logo、戰情總覽、樓層監控、異常警報（帶紅色數字角標 `2`）、月報表匯出。
   - 頂部狀態列：大樓選擇下拉選單（台北信義總部 / 新竹研發園區）、時間範圍切換膠囊（今日即時 / 近 7 日 / 本月）、假裝匯出 CSV 按鈕（點擊顯示 Toast 提示）。
2. 核心數據指標卡（4 欄）：
   - 即時總用電負載（kW）、今日累計碳排放（kgCO₂e）、對比昨日節電率（%）、目前異常警示數。
   - 當切換頂部「今日即時 / 近 7 日 / 本月」時，上述數值與下方圖表數據需隨之動態切換！
3. 中段圖表與異常提醒（左右雙欄）：
   - 左欄（70%）：全棟用電趨勢折線圖（含一條水平虛線標示「契約容量警戒線」）。
   - 右欄（30%）：「即時異常警示清單」，列出 2 筆超標事件（例如：5F 機房冷氣負載過高），點擊該事件會滑出右側詳細排查建議抽屜。
4. 樓層用電明細表：
   - 清楚呈現各樓層（1F–6F）的照明用電、空調用電、總度數與狀態標籤（正常 / 注意 / 超標，需同時含小圓點圖示與文字）。

【視覺規範】
- 專業沉穩的深灰藍調或極淨冷白工業控制室風格（背景 #F4F6F8、純白卡片搭 1px #E2E8F0 細邊框、主要操作色 #0F766E 青綠色）。
```

## 範例 12：《日日動 DailyMove》個人居家運動課表與習慣打卡應用

* **主題**：《日日動 DailyMove》每日 15 分鐘居家伸展與核心運動課表、計時器與連續打卡應用
* **介面**：`互動應用程式（跨裝置習慣追蹤與工具應用 Web / Mobile App）`
* **產品需求**：
  * **專案背景與目標受眾**：久坐上班族想養成每日運動習慣，但常常因為「健身房太遠、不知道今天要練什麼、做一下就放棄」而中斷。需要一個打開就能直接按開始、給足正向成就感的輕量應用。
  * **核心功能與無縫互動需求**：
    1. **頂部連續打卡激勵區**：顯示「🔥 已連續運動 6 天」與本週 7 天小圓點進度條（週一～週日已完成/今日待完成）。
    2. **今日運動課表清單（可勾選）**：列出 4 個輕量動作（如：肩頸放鬆伸展 3 分鐘、平板支撐 2 分鐘、深蹲循環 5 分鐘、核心收操 5 分鐘），勾選完成時進度環／進度條即時往前推進，全部完成時給予慶祝回饋！
    3. **內建「開始計時」互動卡片**：點擊任一動作的「開始計時」，無需跳頁即可進入專注倒數計時器模式（含大字號 `03:00` 倒數、暫停／繼續／重設按鈕，計時歸零自動將該動作標記為完成）。
    4. **課表難度切換**：提供「上班久坐舒緩 / 居家燃脂流汗 / 睡前放鬆」三套預設課表一鍵切換。
  * **UI/UX 與操作要求**：操作極簡直覺、回饋感強烈（Micro-interactions），大按鈕好點擊，即使邊運動邊看螢幕也一眼看懂剩餘秒數。

<details>
<summary>📋 點此展開：可直接複製給 AI 的啟動 Prompt</summary>

```text
請為居家習慣養成應用「日日動 DailyMove」設計一個充滿活力且操作極簡的互動式網頁應用程式（單一 HTML 檔，在桌機上置中以精緻卡片或手機寬度呈現，支援響應式）。

【核心互動與功能規格】
1. 激勵與週進度區：
   - 顯示「🔥 已連續打卡 6 天」徽章與「週一到週日」7 個打卡狀態圓點（完成一個全套課表時，今日圓點即時亮起！）。
   - 頂部顯示今日目標完成度環形進度條或橫向進度條（例如：已完成 1 / 4 項）。
2. 課表主題切換：
   - 三個快速切換膠囊：「💻 久坐肩頸舒緩」、「🔥 15分鐘居家燃脂」、「🌙 睡前拉伸放鬆」，點擊可切換下方的 4 個運動項目內容與秒數。
3. 今日運動任務清單 ＋ 內建倒數計時器（核心互動）：
   - 每個運動項目卡片顯示動作名稱、建議時間、與「直接勾選完成」核取方塊＋「▶ 開始計時」按鈕。
   - 點擊「▶ 開始計時」會開啟（或展開）專注計時面板：顯示超大等寬數字倒數（如 `02:00`）、進度條、開始/暫停、跳過與關閉按鈕。真的能一秒一秒倒數！倒數結束時自動勾選該項目並顯示完成提示。
4. 全部完成回饋：
   - 當今日 4 項動作全數勾選完成時，顯示溫馨的「🎉 今日運動達標！」慶祝卡片。

【視覺規範】
- 明亮充滿朝氣的運動風格：純淨米白底（#F9FAFB）、活力暖珊瑚橘（#F97316）或青檸綠（#10B981）作為達成狀態色，字體清晰大器，避免過度複雜的表格或細碎文字。
```

</details>
