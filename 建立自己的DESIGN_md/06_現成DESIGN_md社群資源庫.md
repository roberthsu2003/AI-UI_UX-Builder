# 06. 現成 DESIGN.md 社群資源庫

> 不想從零開始摸索配色與排版，只想直接看圖挑一個喜歡的樣式來套用？現在網路上已經有許多熱心社群，把世界知名網站的設計系統整理成現成的 `DESIGN.md` 與視覺預覽。這一章帶你認識最好逛的免費資源庫 **DesignMD Gallery**，並教你怎麼保留原本的配色與風格，快速轉成繁體中文網站可用的版本。

---

## 可以去哪裡挑現成的 DESIGN.md？

推薦直接使用 **[DesignMD Gallery（designmd.app）](https://designmd.app/)**：

- **完全免費、免註冊、沒有付費牆**：打開網站就能直接逛，不需要登入或綁定帳號。
- **收錄超過 750 份 `DESIGN.md`**：涵蓋各種產業、知名網站與設計風格。
- **依風格、產業與色系篩選**：可以直接用標籤找方向，點開樣式就能看色票、字型設定並一鍵複製 `DESIGN.md` 內容。

## 挑好之後怎麼直接用？（三步驟）

DesignMD Gallery 上的 `DESIGN.md` 幾乎都是英文網站的規範，直接拿來做繁體中文網頁時，只缺一件事：**適合搭配的中文字型與繁體中文排版設定**。

我們要**完整保留它原本的配色與風格**，只要照著這三步做，就能把這份英文規範轉成繁體中文版來打造全新網站：

### 步驟 1：看預覽，存下一個你最喜歡的 `DESIGN.md`

在 DesignMD Gallery 挑到喜歡的樣式後，直接複製裡面的 `DESIGN.md` 內容，存成專案資料夾裡的 `source-DESIGN.md`。

### 步驟 2：請 AI 幫你「保留原配色與風格，轉成繁體中文版」

把下面這段 Prompt 和 `source-DESIGN.md` 一起交給 AI：

<details>
<summary>📋 Prompt：保留原配色與風格，將社群範本轉成繁體中文 DESIGN.md</summary>

```text
附件 source-DESIGN.md 是我從網路上挑到的設計範本。
我要建立一個全新的繁體中文網站，請完整保留這份範本的「所有配色與視覺風格」，幫我轉成繁體中文版的 DESIGN.md：

- 我的專案主題：【例如：個人作品集／活動報名頁面／手作甜點介紹頁】
- 頁面語言：繁體中文為主、英文數字為輔

請依以下規則產出完整的 DESIGN.md：
1. 完整保留原範本的所有配色（主色、背景色、文字色、強調色等色碼）、排版結構、圓角比例、間距節奏與元件風格，不要更換配色。
2. 把原本的品牌名稱改為我的專案主題（或通用規範描述），並將所有說明與規範整理成清楚好讀的繁體中文。
3. 字型保留原本的英文字型（用於英文與數字），並搭配氣質相符的繁體中文字型（例如 Noto Sans TC、Noto Serif TC、Chiron Hei HK 等免費 Google Fonts），寫明網頁 `<link>` 載入方式與 `font-family` 設定。
4. 整理成標準的兩層格式（上方 YAML Token ＋ 下方 Markdown 章節），方便後續帶到各種 AI 工具使用。
```

</details>

### 步驟 3：準備一份簡單的 `PRD.md`，直接開始做網頁

`DESIGN.md` 決定網站「長什麼樣子」，而 `PRD.md` 決定網站「有哪些區塊與文字」。下面這份精簡範本可以直接複製存成專案裡的 `PRD.md`（也可以把標題與文案換成自己的主題）：

<details>
<summary>📄 可直接複製的簡單 PRD.md 範本</summary>

```markdown
# PRD：我的第一個繁體中文網站

## 1. 網站簡介
- **網站名稱**：晨光筆記 Lumina Notes
- **一句話定位**：幫助學習者整理知識、建立每日複習習慣的輕量數位工具。
- **目標對象**：大學生、自學者與自由工作者。

## 2. 頁面區塊與文案內容

### ① 導覽列（Header）
- 左側品牌名稱：晨光筆記
- 右側導覽連結：功能特色、使用方案、常見問題
- 右側按鈕：立即免費試用

### ② 主視覺區（Hero）
- 主標題：把零散靈感，整理成隨時可查的第二大腦
- 副標題：不用學複雜的設定。打開瀏覽器就能記錄重點、分類標籤，每天花 5 分鐘回顧所學。
- 主要按鈕：開始免費使用
- 次要按鈕：查看示範畫面

### ③ 核心特色（3 張卡片）
1. **快速隨手記**：支援 Markdown 語法與快捷鍵，開會、上課都能跟上紀錄速度。
2. **智慧標籤整理**：自動把相關筆記串聯在一起，找資料不用再翻遍資料夾。
3. **每日複習提醒**：依記憶曲線排程，每天精選 3 則舊筆記幫你加深印象。

### ④ 常見問題（FAQ，3 題）
- **Q1：免費版可以使用哪些功能？**
  A：個人筆記建立、標籤分類與每日複習提醒皆永久免費。
- **Q2：資料可以匯出嗎？**
  A：可以，隨時都能一鍵匯出成標準 Markdown 或 PDF 檔案。
- **Q3：手機上也可以使用嗎？**
  A：支援響應式網頁，電腦、平板與手機都能順暢閱讀與編輯。

### ⑤ 頁尾（Footer）
- 品牌短句：晨光筆記 — 讓每一天的學習都有跡可循
- 聯絡信箱：hello@lumina-notes.example
- 版權宣告：© 2026 晨光筆記 Lumina Notes
```

</details>

把轉好的 `DESIGN.md` 和這份 `PRD.md` 一起交給 AI，送出這句指令就能做出首頁：

```text
請嚴格依照 DESIGN.md 的配色與風格，並根據 PRD.md 的區塊與文案，製作 index.html 首頁（需支援手機版響應式排版）。
```

## 套用現成範本的小提醒

- **確認中英文字型混排的協調度**：因為完整保留了原本的配色與風格，中文字型是否對味會是整體視覺的關鍵（例如科技粗獷風配粗黑體、人文雜誌風配宋體或明體）。除了在步驟 2 讓 AI 自動配對，也可以搭配〈[05. 網頁中英文字型與圖示指南](./05_網頁中英文字型與圖示指南.md)〉挑選最適合的中文字型。
- **社群範本格式不太一樣沒關係**：線上資源庫複製下來的檔案大多偏向純文字描述，而標準格式則有上方 YAML Token。AI 都看得懂；如果你要把檔案匯入 Google Stitch，只要像步驟 2 一樣請 AI 補上 YAML 區塊即可。
- **還是覺得某個細節怪怪的？**：拿著轉好的 `DESIGN.md`，回到〈[04. 建立與驗證自己的 DESIGN.md](./04_建立與驗證自己的DESIGN_md.md)〉做一次 `style-guide.html` 檢查對比與字型，就能微調到最順眼。
