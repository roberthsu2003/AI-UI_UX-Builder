# 05. 網頁中英文字型與圖示指南

> 網站的質感有一半來自「字型」與「圖示」。這一章帶你挑選適合繁體中文網頁的免費中文字型、英文字型與搭配方式，並透過 `DESIGN.md` 與 `AGENTS.md` 讓 AI 自動載入 Google Fonts 與 Google Icons，不再出現系統預設新細明體與廉價 Emoji。

## 先設計、再做網頁：4 大 AI 設計工具與網頁的字體從哪來？

在我們的課程流程中，通常會**「先用 AI 設計工具（Figma、Claude Design、Google Stitch、pen.dev）畫出設計稿 → 確認後再請 AI 轉成真實網頁」**。

不同工具拿字體的方式不同，請先看這張對照表：

| 階段與工具 | 字體從哪裡來？ | 電腦要裝字型嗎？ | 如何讓 AI 用對字體？ |
| :--- | :--- | :---: | :--- |
| **1. Claude Design**<br>（Artifacts 設計畫布） | 本質是即時網頁，**從網路 CDN 即時下載** | ❌ 不用 | 在 `DESIGN.md` 或 Prompt 指定字型，並要求在 `<head>` 加入 Google Fonts `<link>`（或 B 區 `@font-face`） |
| **2. Google Stitch** | **內建 Google Fonts 雲端字庫** | ❌ 不用 | 只認得 **A 區 Google Fonts**（不支援 B 區自架字型）；在 `DESIGN.md` 寫英文正式名（如 `Noto Serif TC`）即可自動套用 |
| **3. Figma × MCP**<br>（AI 控制 Figma） | Google Fonts 雲端字庫 ＋ **你電腦本機安裝的字型** | ✅ **強烈建議安裝** | Figma 桌面版最挑剔字型名稱；先在電腦裝好字型，並在 `DESIGN.md` 寫英文正式名（如 `Noto Sans TC`），AI 透過 MCP 寫入才不會報錯 |
| **4. pen.dev（Pencil）**<br>（`.pen` 向量畫布） | Google Fonts 雲端字庫 ＋ **你電腦本機安裝的字型** | ⭕ A 區不用裝；<br>B 區**要裝到電腦** | AI 會直接讀取 `DESIGN.md` 的 `fontFamily` 套用到 `.pen` 文字節點；用 `browser` 節點預覽時則從網路 CDN 下載 |
| **5. 最後轉成真實網頁**<br>（HTML / React） | 訪客打開網頁時，**瀏覽器自動從網路 CDN 下載** | ❌ 訪客不用裝 | 設計稿本身**不會夾帶字型檔**！轉網頁時必須讓 AI 自動在 HTML `<head>` 補上 Google Fonts `<link>` 或 `@font-face` |

### 📦 如何下載與安裝字型到電腦（macOS ／ Windows）

如果你要搭配 **Figma 桌面版、pen.dev 或 PyQt6 桌面軟體** 使用，請先把字型安裝到自己的電腦：

1. **從 Google Fonts 下載**：
   - 點開字型頁面（例如 [Noto Sans TC](https://fonts.google.com/noto/specimen/Noto+Sans+TC)、[Noto Serif TC](https://fonts.google.com/noto/specimen/Noto+Serif+TC)），點右上角 **「Get font」** → **「Download all」**，下載後將 `.zip` 解壓縮。
   - 解壓縮後可以直接安裝外層的**可變字型檔**（檔名含 `VariableFont_wght.ttf`，一個檔案就包含所有粗細），或進到 `static/` 資料夾全選所有 `.ttf`／`.otf` 字型檔。
2. **macOS 安裝步驟**：
   - **方法 A（雙擊安裝）**：選取 `.ttf` 或 `.otf` 字型檔，直接按兩下打開「字體簿（Font Book）」，點擊右下角的 **「安裝（Install）」**。
   - **方法 B（批次拖曳）**：打開「應用程式 → 字體簿」，把解壓縮出來的字型檔直接拖進「所有字體」或「我的字體」清單中。
3. **Windows 安裝步驟**：
   - **方法 A（右鍵批次安裝，最推薦）**：在檔案總管全選所有 `.ttf` 或 `.otf` 字型檔 → 按滑鼠右鍵 → 點選 **「安裝」**（或 **「為所有使用者安裝」**）。
   - **方法 B（設定頁面拖曳）**：打開「設定 → 個人化 → 字型」，把字型檔直接拖進「拖曳以安裝」的虛線框內。
4. **安裝後記得重開軟體**：安裝完成後，**重新啟動 Figma 桌面版、pen.dev 或終端機**，新字型才會出現在字型選單中。

## 繁體中文網頁字型推薦（不只思源黑體與宋體）

做網頁時，我們希望**「免費開源、可商用、CDN 載入快、繁體字不會缺字」**。以下依載入方式分為兩類：

> [!TIP]
> **課前建議安裝清單**：如果你會在電腦上搭配 **Antigravity、Figma 桌面版或 pen.dev** 進行設計，強烈建議把下方 **A 區（7 款）與 B 區（5 款）共 12 款繁體中文字型**都先下載安裝到電腦中，這樣設計畫布與預覽都能直接顯示正確字型、不會缺字或報錯！

### A. Google Fonts 直接可用（最穩定、免自架、AI 最熟）

這 7 款字型不僅建議安裝到電腦本機，做網頁時也只要一行 `<link>` 就能直接載入，Google 已幫中文字做好自動分塊（Subsetting），**不會缺字、載入速度最快**：

#### 🌐 如何在網頁上用 CDN 載入這些台灣開源字型？

中文字型檔一整包通常有 8～20 MB，直接丟上網站會載入很慢。推薦以下兩種免費 CDN 載入方式：

1. **正式網站推薦：使用 [emfont](https://font.emtech.cc/)（台灣免費開源中文 WebFont CDN）**
   - 收錄了**粉圓體、辰宇落雁體、源流明體、源樣黑體、俐方體 Cubic 11** 等台灣開源字型。
   - 它會自動掃描你網頁上實際用到的中文字，只下載那幾十個字（僅幾十 KB），速度跟 Google Fonts 一樣快。
2. **課堂原型／單頁 HTML 快速預覽：使用 jsDelivr CDN（`@font-face`）**
   - 如果你在 Claude Artifacts 或本機做單頁原型，可以直接請 AI 在 CSS 裡加上 `jsDelivr` 的 CDN 網址（以下以 **jf open 粉圓** 與 **俐方體 Cubic 11** 為例）：

```css
/* 載入 jf open 粉圓體 */
@font-face {
  font-family: 'jf-openhuninn';
  src: url('https://cdn.jsdelivr.net/gh/justfont/open-huninn-font@1.1/font/jf-openhuninn-1.1.ttf') format('truetype');
  font-display: swap;
}

/* 載入 Cubic 11 俐方體（WOFF2 網頁壓縮版，載入更快） */
@font-face {
  font-family: 'Cubic 11';
  src: url('https://cdn.jsdelivr.net/gh/ACh-K/Cubic-11@v1.451/fonts/web/Cubic_11.woff2') format('woff2');
  font-display: swap;
}
```

## 英文字型推薦（中英混排的關鍵技巧）

中文網頁一定會出現 **英文品牌名、價錢數字（NT$ 480）、日期（2026.11.20）、數據圖表**。如果只寫 `Noto Sans TC`，裡面的英文字母和數字常常顯得偏窄、不夠精緻。

> [!TIP]
> **中英混排黃金法則：英文字型寫在前面、中文字型寫在後面！**
> 例如：`fontFamily: "'Plus Jakarta Sans', 'Noto Sans TC', sans-serif"`
> 瀏覽器遇到英文與數字時，會優先套用前面精緻的英文字型；遇到中文字時，才會自動往後找 `Noto Sans TC`。

以下都是 Google Fonts 上**免費且載入極快**的精選英文字型：

### 1. 無襯線字（現代 SaaS、極簡、介面、便當盒）
- **[Inter](https://fonts.google.com/specimen/Inter)**：UI 介面界的標準字，極高易讀性、表格與小字表現最好。
- **[Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)**：比 Inter 多了一點幾何圓潤感與現代品牌溫度，近年 SaaS 與設計工作室最常用。
- **[DM Sans](https://fonts.google.com/specimen/DM+Sans)**／**[Manrope](https://fonts.google.com/specimen/Manrope)**：幾何感明確、線條友善，與 `Noto Sans TC` 混排視覺重量非常平衡。

### 2. 個性幾何大標（瑞士格線、新粗野主義、策展活動）
- **[Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk)**：帶有科技與微怪誕感的幾何無襯線字，特別適合新粗野主義、設計展、AI 產品。
- **[Outfit](https://fonts.google.com/specimen/Outfit)**／**[Syne](https://fonts.google.com/specimen/Syne)**：寬闊且有視覺張力的展示型標題字，適合做大字報或 Hero 主視覺。

### 3. 優雅襯線字（編輯雜誌、暗黑奢華、精品、咖啡館）
- **[Playfair Display](https://fonts.google.com/specimen/Playfair+Display)**：高對比時尚雜誌感，做精品或咖啡館的英文副標、數字編號非常好看。
- **[Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond)**：筆畫纖細古典、氣質高級，適合暗黑奢華、香氛、藝廊網站。
- **[Newsreader](https://fonts.google.com/specimen/Newsreader)**／**[Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif)**：現代編輯刊物感，適合長篇閱讀與文化類網站。

### 4. 等寬字型（價格、時間、編號、儀表板數據）
- **[JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)**：數字辨識度高、寬度固定不跳動，最適合價格、倒數計時與數據儀表板。
- **[Space Mono](https://fonts.google.com/specimen/Space+Mono)**／**[IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono)**：適合用在雜誌風日期標籤（`2026.11.20`）、票券編號或技術規格表。

## 如何讓 AI 在「設計 → 轉網頁」全程自動用對字體？

從設計稿轉成真實網頁時，最常發生**「設計稿上看得到字體，轉成網頁卻變回新細明體」**。因為設計稿只記錄了「字型名字」，**不會夾帶字型檔案**；網頁必須透過網路（CDN）下載字型才看得到。

只要在 `DESIGN.md` 遵守這兩條規則，AI 在設計與轉網頁時就能一路無縫接軌：

### 規則 1：`DESIGN.md` 一律寫「英文正式名稱」

不要只寫中文「思源宋體」或「粉圓體」，請一律寫成工具與程式認得的**英文正式名稱**（例如 `Noto Serif TC`、`Chiron Hei HK`、`Plus Jakarta Sans`）。這樣 **Figma MCP、Google Stitch、pen.dev、Claude Design** 與最後轉出來的網頁程式碼才能對得上同一個字型。

### 規則 2：在 `DESIGN.md` 的 `## Typography` 加上「轉網頁自動載入 CDN」指令

在 `DESIGN.md` 中，除了在上方 YAML 定義 `fontFamily`，請務必在下方的 `## Typography` 章節寫清楚「轉網頁時要自動從網路下載字型」：

#### 寫法 A：使用 Google Fonts 字型（最推薦，4 大設計工具皆支援）

```markdown
---
typography:
  headline:
    fontFamily: "'Playfair Display', 'Noto Serif TC', serif"
  body:
    fontFamily: "'Plus Jakarta Sans', 'Noto Sans TC', sans-serif"
---

## Typography
- **設計階段**：Figma / pen.dev / Stitch 請直接套用上述英文正式字型名稱。
- **轉成網頁階段（重要）**：生成 HTML 或 React 網頁時，**必須在 `<head>` 自動加入 Google Fonts 的 `<link>`** 載入 `Playfair Display`、`Plus Jakarta Sans`、`Noto Serif TC` 與 `Noto Sans TC`；不可只寫 CSS `font-family` 而漏掉 `<link>`。
```

#### 寫法 B：使用 B 區「台灣開源特色字型」（例如粉圓體、俐方體）

因為 B 區字型不在 Google Fonts 上，AI 自己猜下載網址很容易寫錯，請把 `@font-face` CDN 網址**直接貼進 `DESIGN.md`**：

```markdown
## Typography
- **設計階段**：請先將「jf open 粉圓」安裝於本機電腦，再讓 Figma / pen.dev 使用字型名稱 `jf-openhuninn`。
- **轉成網頁階段（重要）**：生成網頁 CSS 時，請在樣式表最上方加入以下 CDN 下載語法，再於 `font-family` 使用 `'jf-openhuninn', 'Noto Sans TC', sans-serif`：
  @font-face {
    font-family: 'jf-openhuninn';
    src: url('https://cdn.jsdelivr.net/gh/justfont/open-huninn-font@1.1/font/jf-openhuninn-1.1.ttf') format('truetype');
    font-display: swap;
  }
```

> [!NOTE]
> **白話原理：網頁到底怎麼「下載」字型？**
> 1. **向雲端點外送（`<head>` 裡的 `<link>` 或 `@font-face`）**：訪客打開你的網址時，瀏覽器會在背景向 Google 或 CDN 伺服器下載這個字型檔（只存在瀏覽器暫存中，訪客電腦不用安裝）。
> 2. **把字體擺上桌（CSS 的 `font-family`）**：把下載好的字型套用到標題或內文上。
> **兩步缺一不可**：只寫 CSS 沒寫 `<link>`，網頁就會退回系統預設新細明體。

2. 同時在 `DESIGN.md` 寫明**轉成網頁時要用 Google Fonts `<link>` 還是 `@font-face` / `emfont` CDN 下載字型**；
3. 網頁介面一律改用 **Google Material Symbols** 向量圖示，禁止使用廉價的 Emoji（如 🔍、📅、⚙️、🛒）。

> - **`AGENTS.md`（全域工作守則）**：規定 AI 工具的執行紀律（生成 `DESIGN.md` 時可選用哪些繁中字型、轉網頁必載 CDN `<link>`、必用 Google Material Symbols 取代 Emoji）。

## 1. 生成或修改 `DESIGN.md` 時的字型規範

當使用者請你建立或更新 `DESIGN.md` 時：

### A. 必須從以下「本機已安裝且支援網頁 CDN」的字型庫中挑選搭配

   - `Noto Serif TC`（思源宋體：編輯雜誌、暗黑奢華、老宅、茶飲、文化大標）

   - `Chiron Sung HK`（昭源宋體：編輯雜誌、策展、深度報導、精品標題）
   - `Zen Maru Gothic`（禪丸圓體：柔和療癒、甜點、親子、寵物，需搭 `Noto Sans TC` 後備）
   - `LXGW WenKai TC`（霞鶩文楷 TC：文青、獨立書店、茶香氛、引言標語）
   - `DotGothic16`（點陣體：新粗野主義、獨立遊戲裝飾標題，需搭 `Noto Sans TC` 後備）
2. **繁體中文字型（B 區：台灣開源特色字型，本機已安裝、網頁需搭配 CDN）**：
   - `jf-openhuninn`（jf open 粉圓：柔和療癒、美食飲品、親子品牌）
   - `GenRyuMin TW`（源流明體：編輯雜誌、老宅品牌大標題）
   - `GenYoGothic TW`（源樣黑體：文化品牌、展覽活動）
   - `Cubic 11`（俐方體 11 號：復古科技、遊戲專題、新粗野主義）
   - `ChenYuluoyan`（辰宇落雁體：主視覺單句感性標語點綴，不可用於長篇內文）
3. **英文字型（Google Fonts，負責英文與數字顯示）**：
   - 無襯線：`Inter`、`Plus Jakarta Sans`、`DM Sans`、`Manrope`
   - 幾何大標：`Space Grotesk`、`Outfit`、`Syne`

   - 等寬數字：`JetBrains Mono`、`Space Mono`、`IBM Plex Mono`

### B. `DESIGN.md` 必寫格式與規則
1. **中英混排順序**：所有 `fontFamily` 必須「**英文字型在前、繁體中文字型在後**」（例如 `'Playfair Display', 'Noto Serif TC', serif`），且一律使用上述**英文正式字型名稱**。
2. **必須寫出網頁載入方式**：在 `DESIGN.md` 的 `## Typography` 章節，**必須明確列出該專案選用字型的「網頁下載方式」**：
   - 若選用 **A 區（Google Fonts）**：寫明轉網頁時必須於 HTML `<head>` 自動加入對應的 Google Fonts `<link>`。
   - 若選用 **B 區（台灣開源字型）**：寫明轉網頁時必須於 CSS 加入 `@font-face`（jsDelivr CDN）或 `@import url("https://font.emtech.cc/css/<emfont字型ID>")`（emfont CDN），不可只寫 `font-family` 而沒有網路載入語法。

## 3. 網頁端（HTML / Tailwind / React）強制規範

### A. 必須在 `<head>` 引入 Google Fonts 與 Google Icons（Material Symbols）
生成任何 HTML 頁面時，**必須依照 `DESIGN.md` 指定的字型**，在 `<head>` 自動加入對應的 Google Fonts `<link>`（以下示範載入常用組合）與 Google Material Symbols 圖示庫：

```html
<!-- Google Fonts：依 DESIGN.md 實際指定的字型動態調整 family 參數 -->
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link
  href="https://fonts.googleapis.com/css2?family=Chiron+Hei+HK:wght@400..700&family=Chiron+Sung+HK:wght@500..700&family=JetBrains+Mono:wght@400;500;600;700&family=Noto+Sans+TC:wght@400;500;600;700&family=Noto+Serif+TC:wght@500;600;700&family=Playfair+Display:wght@600;700&family=Plus+Jakarta+Sans:wght@400;500;600;700&display=swap"
  rel="stylesheet"
/>

<!-- Google Icons：Material Symbols Outlined（可變圖示字型） -->
<link
  href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200"
  rel="stylesheet"
/>
```

若 `DESIGN.md` 選用了 **B 區台灣開源字型**，必須在 `<style>` 或全域 CSS 最上方加入 CDN 載入語法（擇一）：
```css
/* 方式一：透過 jsDelivr CDN 載入（範例：jf open 粉圓 / Cubic 11 / 源流明體） */
@font-face {
  font-family: 'jf-openhuninn';
  src: url('https://cdn.jsdelivr.net/gh/justfont/open-huninn-font@1.1/font/jf-openhuninn-1.1.ttf') format('truetype');
  font-display: swap;
}

/* 方式二：透過 emfont 動態子集化 CDN 載入（需依 emfont 官網確認字型 ID，例如 jfOpenHuninn） */
/* @import url("https://font.emtech.cc/css/jfOpenHuninn"); */
```

### B. 圖示使用規定（禁止用 Emoji 充當 UI 圖示）
- 導覽列、按鈕、搜尋框、關閉按鈕、狀態標籤**一律使用 Google Material Symbols**，禁止使用 Emoji（如 🔍、📅、⚙️、🛒）當作正式介面圖示。
- 標準 HTML 寫法與對齊 CSS：
  ```html
  <span class="material-symbols-outlined">calendar_month</span>
  ```
  ```css
  .material-symbols-outlined {
    font-variation-settings: 'FILL' 0, 'wght' 400, 'GRAD' 0, 'opsz' 24;
    font-size: 20px;
    vertical-align: middle;
    line-height: 1;
  }
  ```
- 若需切換為「已收藏 / 已選中」實心狀態，將 `'FILL'` 設為 `1`。

### C. 中英混排字體套用規則
- 英文字型永遠寫在繁體中文字型前面，讓英數字與中文各自呈現最佳外觀。
- 價格、電量、倒數時間數字：`font-family: 'JetBrains Mono', monospace; font-variant-numeric: tabular-nums;`

## 4. 桌面應用程式端（PyQt6）強制規範

- **字體優先順序**：在全局 QSS 中一律設定 `font-family: "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", sans-serif;`（確保已安裝本機字型時能優先啟用，跨 Windows/macOS 維持一致）。
- **圖示處理**：PyQt6 離線桌面視窗無法直接使用網頁 CSS `<link>`，請使用 `QIcon` 載入標準的 **Google Material Symbols SVG**（或以內嵌精簡 SVG 字串透過 `QSvgRenderer` / `QPainter` 繪製向量圖示），禁止使用會因作業系統不同而變形的 Emoji 當作按鈕圖示。
