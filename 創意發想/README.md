# 創意發想與設計靈感庫 (Design Inspiration & Brainstorming) 💡

在動手畫原型或讓 AI 生成網頁之前，**「腦袋裡有畫面」** 是決定設計品質最關鍵的一步。如果沒有看過足夠多優秀、成熟的實際作品，直接請 AI 產生畫面，往往只能得到最平庸的公版。

本單元精選了設計師與 Builder 在不同階段最常使用的**靈感與創意發想資源庫**，從可直接複用的 Figma 社群檔案、真實世界頂尖產品拆解，到視覺衝擊強烈的前端動態網站：

---

## 🎨 核心靈感資源庫推薦

### 1. [Figma Community (社群)](https://www.figma.com/community) — 最實用的設計資產庫
* **核心特色**：全世界設計師開源的 UI Kits、設計系統（Design Systems）、Wireframe 模板、Icon 圖示庫與外掛。
* **最佳用法**：
  * **複製現成 UI Kit**：搜尋如 `Landing page kit`、`iOS UI Kit`、`Dashboard design system`，直接「Duplicate（複製）」到自己的 Figma 檔案中拆解學習。
  * **學習規範**：觀摩知名團隊（如 Ant Design、Shopify Polaris、Material Design）如何命名圖層、設定 Auto Layout 與管理 Variables。

### 2. [Mobbin](https://mobbin.com/) — 真實上線 App 與 Web 的畫面流程庫
* **核心特色**：專門收錄全球頂尖真實產品（Airbnb, Uber, Notion, Linear, Spotify 等）的完整截圖與 User Flow（使用者流程）。
* **最佳用法**：
  * **查特定功能動線**：想知道業界最好的「註冊登入（Onboarding）」、「結帳付款（Checkout）」或「搜尋篩選（Filter）」怎麼做，直接在此搜尋畫面流程。
  * **跨裝置對照**：同時支援 iOS、Android 與 Web 端截圖，適合觀察不同螢幕尺寸下的佈局手法。

### 3. [Dribbble](https://dribbble.com/) & [Behance](https://www.behance.net/) — 視覺風格與美學概念發想
* **核心特色**：設計師展示概念創作（Concept Design）、前衛視覺風格、品牌識別（Branding）與微互動動效的集散地。
* **最佳用法**：
  * **探索大膽視覺**：當你想突破傳統框架，尋找驚艷的色彩搭配、排版字體比例或卡片風格時，是尋找 Moodboard（情緒板）的最佳起點。
  * **注意**：部分作品偏向概念展示，實務上需配合可用性與工程可行性加以過濾。

### 4. [Awwwards](https://www.awwwards.com/) & [FWA](https://thefwa.com/) — 前端極致互動與動態創意
* **核心特色**：全球最頂尖的網頁設計與動態獲獎作品，著重 3D、WebGL、流暢轉場與捲動敘事（Scrollytelling）。
* **最佳用法**：
  * **動態與空間感啟發**：尋找網頁前所未見的互動效果（如 3D 視差、液態效果、一鏡到底）。
  * 搭配本課程的 [前端動態框架圖鑑](../前端動態框架圖鑑/README.md) 一起對照，找出獲獎網站背後使用的是哪套技術（Three.js, GSAP 等）。

### 5. [Land-book](https://land-book.com/) & [Lapa Ninja](https://www.lapa.ninja/) — 精選 Landing Page 專門站
* **核心特色**：專為登陸頁（Landing Page）、SaaS 官網、新創募資頁面收集的優秀案例庫。
* **最佳用法**：
  * **依行業類別瀏覽**：分類清晰（科技、電商、教育、個人作品集等），能快速找到同性質產品的標準結構與定價方案區塊（Pricing Table）。

## 🛠️ 如何把靈感轉化為 AI 的精確提示？

當你在上述網站看到喜歡的版型或氛圍時，不要只是截圖存檔，請搭配以下步驟讓 AI 幫你實現：

1. **萃取設計特徵**：
   * 這是單欄還是多欄佈局？留白是緊湊還是寬鬆？
   * 它的主要視覺焦點是照片、插畫還是 3D 元素？
2. **文字化描述**：
   * 將看到的視覺亮點寫進提示詞：「*參考現代 SaaS 簡潔高對比風格，具有細微毛玻璃導覽列、深色卡片與微漸層發光外框⋯⋯*」
3. **固化成規範**：
   * 把萃取出的色彩、字體與元件原則記錄到你的 [DESIGN.md](../建立自己的DESIGN_md/README.md) 中，讓 AI 在後續製作多頁面時都能維持同一套風格。
