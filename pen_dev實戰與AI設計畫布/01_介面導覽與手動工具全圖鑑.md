# 01. pen.dev 介面導覽與手動工具全圖鑑

> **學習目標**：即使是由 AI 主導生成設計，你仍然必須看得懂、改得動畫布上的每一個元素。本篇帶你認識 `pen.dev` 的工作區配置、所有快捷鍵、**13 種畫布節點**，以及右側屬性面板的 **Fills（填充）與 Effects（特效）**，並透過 Lab 1 親手完成「AI 生成 → 手動微調」的第一個循環。

---

## 一、介面五大工作區與必背快捷鍵

打開 `pen.dev` 並建立或開啟一個 `.pen` 檔案後，畫面分為五大區塊：

1. **Top Bar（頂部工具列與分頁）**：包含首頁（Home / Recents / Drafts / Design Systems）、已開啟的 `.pen` 檔案分頁、檢視縮放比例與匯出入口。
2. **Left Panel（左側圖層與元件面板）**：
   * **Layers（圖層樹）**：檢視畫布上的 `frame`、`group`、`text` 等巢狀結構。
   * **Assets / Components（元件庫）**：集中管理所有設定為 Reusable 的元件（`reusable: true`）與 Variants 變體集。
3. **Center Infinite Canvas（中央無限向量畫布）**：容納所有設計畫框、便利貼、互動網頁節點（`browser`）與程式腳本節點（`script`）。
4. **Right Panel（右側屬性面板）**：
   * 選取不同節點時動態切換：位置尺寸（W/H）、**Flex 自動排版（Layout）**、文字（Typography）、**填充（Fills）**、**描邊（Stroke）**、**特效（Effects）**、設計變數（Variables），以及 `script`/`shader` 專屬的**互動滑桿控制項**。
5. **AI Sidebar & Command Palette**：隨時按快捷鍵喚出 AI 對話側邊欄或指令面板。

### 常用快捷鍵速查表

| 功能類別 | 快捷鍵（Mac / Windows） | 說明與應用時機 |
| :--- | :--- | :--- |

## 二、13 種畫布節點與手動工具全圖鑑

在 `.pen` 檔案格式（Schema v2.25）中，你在畫布上看到的一切都屬於以下 **13 種核心節點與概念**。了解它們的手動參數，就能看懂 AI 寫出來的設計稿並隨時接手修改。

### 1. 容器與 Flex 自動排版：`frame`（快捷鍵 `A` 或 `F`、`Shift + A`）

`frame` 是網頁區塊與 UI 元件的核心容器（可設 `clip: true` 裁切超出邊界的內容）。選取兩個以上物件或單一 Frame 按 **`Shift + A`**，即可開啟 **Flex Layout**：

* **`layout`（方向）**：`"horizontal"`（橫排）、`"vertical"`（直排）或 `"none"`（自由定位，僅適合純視覺裝飾背景，UI 排版應盡量開啟 Flex）。
* **`gap`（間距）**：子元素之間的統一像素間距（例如 `16`）。
* **`padding`（內距）**：容器邊緣與內容的距離，可設單一數值、`[上下, 左右]` 或 `[上, 右, 下, 左]`。
* **`justifyContent`（主軸對齊）**：`"start"`、`"center"`、`"end"`、`"space_between"`、`"space_around"`。
* **`alignItems`（交錯軸對齊）**：`"start"`、`"center"`、`"end"`。
* **尺寸三態（Width / Height）**：
  * **固定像素（Fixed）**：例如 `320`（數值單位為 px）。
  * **隨內容縮放（`fit_content` / UI 顯示 Hug）**：容器自動緊貼內部文字或子元素大小。
  * **填滿父容器（`fill_container` / UI 顯示 Fill）**：子元素自動撐滿父層扣除 `padding` 後的剩餘空間。

> [!WARNING]
> **`.pen` Flex 排版三大鐵則（學生手動與 Prompt 必知）**：
> 1. **沒有百分比寬度**：不要寫 `"100%"`，要填滿父容器請改為 **`fill_container`**。
> 2. **沒有 `margin` 屬性**：元素之間的距離一律透過父層的 **`gap`** 與 **`padding`** 控制（或插入固定寬高的透明 spacer frame）。
> 3. **沒有 `alignItems: "stretch"`**：要讓子元素在橫軸撐滿，請直接在該子元素的 `width` 或 `height` 設為 **`fill_container`**。

### 2. 基礎幾何與向量圖形：`rectangle`、`ellipse`、`polygon`、`path`、`line`

| 節點類型 | 快捷鍵 | 關鍵可調屬性（右側面板 / Schema） | 實戰技巧 |
| :--- | :--- | :--- | :--- |
| **`rectangle`** | `R` | `cornerRadius`（支援單一數字或四角陣列 `[左上, 右上, 右下, 左下]`） | 製作卡片、按鈕底板、標籤與圖片裁切框。 |
| **`ellipse`** | `O` | `innerRadius`（內圈半徑比例 `0~1`）、`startAngle`（起始角度）、`sweepAngle`（掃描角度） | **超實用技巧**：不只能畫正圓！將 `innerRadius` 設為 `0.75`、`sweepAngle` 設為 `270`，一秒變成**儀表板圓環進度條或圓餅圖**。 |
| **`polygon`** | 工具列多邊形 | `polygonCount`（邊數，預設 6）、`cornerRadius` | 製作六角形徽章、三角形指示箭頭或星芒底圖。 |
| **`path`** | `P`（鋼筆工具） | `geometry`（SVG Path 字串如 `M0 0 L10...`）、`fillRule`（`"nonzero"` / `"evenodd"`） | 繪製客製化波浪、品牌 Logo 曲線；AI 生成 SVG 後也能用 `P` 手動拖曳貝茲控制點微調！ |
| **`line`** | 工具列線段 | 起終點尺寸、`stroke`（線寬、虛線 `dashPattern`、端點樣式 `cap`） | 製作分隔線、時間軸連接線或格線輔助。 |

---

### 3. 文字與圖示：`text`（快捷鍵 `T`）與 `icon`

* **`text`（文字節點）**：
  * **換行模式（`textGrowth`）三選一**：
    1. `"auto"`：寬高都隨字數自動撐開（適合按鈕文字、短標籤）。
    2. `"fixed-width"`：**網頁內文最常用！** 固定寬度（或設 `fill_container`），文字太長時會自動向下換行撐高容器。
    3. `"fixed-width-height"`：寬高都寫死，超出時需注意是否被截斷。
  * **常見新手陷阱**：`.pen` 中的 `text` 節點預設沒有填色，若只給文字內容沒設定 **`fill`**，畫面上會一片透明看不見！手動新增文字或請 AI 生成時務必指定字體色。
  * 支援 `fontFamily`（可使用如 `Noto Sans TC`、`Inter`）、`fontSize`、`fontWeight`、`lineHeight`、`letterSpacing`、`textAlign`。
* **`icon`（向量圖示節點）**：
  * 不必另外找 SVG 檔案！`pen.dev` 內建 **6 大主流向量圖示庫**，直接在右側面板選取圖示名稱（`iconFontName`）與圖示庫（`iconFontFamily`）即可切換：
    * **`Material Symbols Outlined`** / **`Material Symbols Rounded`** / **`Material Symbols Sharp`**（支援 `weight: 100~700` 粗細調整！）
    * **`lucide`**（極簡細線風格，SaaS 與儀表板首選）
    * **`feather`**
    * **`phosphor`**

---

### 4. 群組、便利貼與元件變體：`group`、`note`、`ref` / `variants`

* **`group`（`Cmd/Ctrl + G`）**：純粹把多個零散向量綁在一起方便移動，**不支援 `fill`、裁切或 Flex 排版**。要做 UI 排版時，請優先使用 `Cmd/Ctrl + Option/Alt + G` 包進 **`frame`**。
* **`note`（畫布便利貼）**：支援 `content` 文字內容與便利貼底色（預設 `#FEE484` 黃色）。**課堂協作妙用**：學生想請 AI 修改某個區塊時，除了框選該區塊，也可以在旁邊貼一張 `note` 寫下修改需求，AI 掃描畫布時會一併讀取！
* **元件與變體系統（Reusable Components & Variants）**：
  1. 選取一個設計好的按鈕或卡片 Frame，按 **`Cmd/Ctrl + Option/Alt + K`**，它會成為主元件（Main Component，`reusable: true`，左上角出現菱形圖示）。
  2. 從左側 Components 面板拖出使用時，產生的分身叫做 **`ref`（實例）**。修改主元件，所有分身會同步更新；若只想改單一分身的文字或圖示，直接在分身內編輯（底層稱為 **`descendants` 覆寫**），不會破壞主元件連結。
  3. 選取多個相似元件（例如「預設按鈕 / 懸停按鈕 / 禁用按鈕」），按 **`Shift + Cmd/Ctrl + K`** 合併為 **`variants`（元件變體集）**，之後在右側面板就能像切換開關一樣用下拉選單切換 `state` 或 `size`！

---

### 5. 進階互動節點：`browser` 與 `script`（簡介）

* **`browser`（畫布內嵌瀏覽器節點）**：把一個真實可點擊、可捲動的網頁（如 `http://localhost:3000` 或參考網站）直接放進設計畫布上，還能切換桌面或手機外框（`deviceId: "phone"`）。
* **`script`（參數化程式節點）**：連結一份 `.js` 腳本，動態在畫布上繪製複雜網格、資料圖表或幾何背景，並在右側面板自動生成滑桿給學生手動調整（詳見 [第 03 章](./03_Generate生圖轉向量與Script_Shader特效.md)）。

## 三、右側面板 Fills（填充）與 Effects（特效）全解析

選取任何 `frame`、`rectangle`、`ellipse` 或 `path` 時，右側面板支援以下 **5 種填充** 與 **4 種特效**：

### 5 種填充模式（Fills）
1. **純色（`color`）**：支援 HEX / RGBA 色碼，或綁定 Design Variables（例如 `"$primary"`）。
2. **線性／放射／角度漸層（`gradient`）**：可設定 `linear`、`radial`、`angular`（錐形漸層），自由拖曳畫布上的色標與角度軸。
3. **圖片填充（`image`）**：支援上傳圖片、AI 生成填入或圖庫填入，縮放模式包含 `fill`（覆蓋裁切）、`fit`（完整容納）、`stretch`（拉伸），並可透過裁切矩陣調整焦點位置。
4. **網格漸層（`mesh_gradient`）**：透過網格節點（`columns × rows`）與貝茲控制柄，調出蘋果官網風格的高級流光漸層背景。
5. **WebGL 著色器填充（`shader`）**：直接套用 `.glsl` 片段著色器，做出動態噪點、流動極光與光學玻璃折射效果。

### 4 種視覺特效（Effects）
1. **陰影（`shadow`）**：可切換 **Drop Shadow（外陰影）** 或 **Inner Shadow（內陰影）**，調整 `offset`（X/Y 位移）、`blur`（模糊半徑）、`spread`（擴散）與顏色（也支援混合模式 `blendMode`）。
2. **圖層模糊（`blur`）**：將該物件本身變模糊，常搭配背景光暈球體使用。
3. **背景模糊（`background_blur`）**：製作 iOS 風格 **毛玻璃（Glassmorphism）** 的核心特效！將卡片填充色設為半透明（如 `rgba(255,255,255,0.65)`），再開啟 `background_blur`（如半徑 `20`），底下的色彩就會透出柔和霧面質感。
4. **後製著色器特效（`shader`）**：套用全域後製濾鏡或折射特效。

## 四、動手實作 Lab 1：AI 生成元件庫卡片 → 學生手動微調所有基礎工具

這個練習的目標是讓你實際體驗「**AI 一次排好乾淨結構，你親自用 `pen.dev` 介面修改細節**」的流暢手感。

### 步驟一：請 AI 生成練習用畫布元件
1. 在 `pen.dev` 開啟一個空白的 `lab01_tools.pen` 檔案。
2. 按 **`Cmd/Ctrl + K`** 開啟 AI 側邊欄（或使用連接好 Pencil MCP 的 Antigravity），貼上你的 Prompt。

> [!IMPORTANT]
> **Prompt 撰寫注意事項（寫出結構優良的畫布指令）**：
> 1. **明確指定節點種類**：告訴 AI 要用哪些節點（例如：圓環進度條要用 `ellipse` 的 `innerRadius` 與 `sweepAngle`，圖示要用內建 `icon` 而不是硬畫線段）。
> 2. **要求強制使用 Flex Auto Layout**：禁止 AI 用絕對座標硬疊，明確規定父層要用 `horizontal` / `vertical`、`gap` 與 `padding`。
> 3. **提醒文字填色與 `textGrowth`**：請 AI 務必為每個 `text` 設定明確的 `fill` 顏色與 `"fixed-width"`（針對長段說明文），才不會在畫面上看不見或跑版。
> 4. **要求順便貼一張 `note` 便利貼**：讓 AI 在畫框旁留一張任務便利貼，方便你等一下按表操作練習。

### 步驟二：學生在 `pen.dev` 介面親自動手修改 5 件事
AI 生成完成後，請**不要再下 Prompt**，親自用滑鼠與快捷鍵完成以下操作，熟悉每個面板的位置：

1. **導覽與聚焦**：點擊圖層中的 `ProfileCard`，按下 **`Shift + 2`** 讓卡片居中放大；再按住 **`Space` + 拖曳滑鼠**平移畫布看旁邊的 `note` 便利貼。
2. **微調 Flex 排版**：選取 `ProfileCard`，在右側面板找到 **Layout** 區塊，手動將 `padding` 從 `24` 改成 `32`、把 `gap` 改成 `24`，觀察卡片如何自動長高而不會重疊。
3. **操作圓環 `ellipse` 參數**：點開圓環群組，選中上層的藍色進度圈，在右側面板找到 **Sweep Angle**（掃描角度），手動把 `288`（80%）改為 **`324`**（90%），親眼看它變成 90% 圓環！
4. **切換內建 `icon` 圖示**：點選卡片裡的 `icon` 節點，在右側面板嘗試把 `iconFontFamily` 切換成 `Material Symbols Rounded`，並把 `weight` 從 `500` 調成 `700`，或直接更換另一顆圖示名稱（例如 `rocket_launch`）。
5. **練習 Reusable Component 連動**：點選被設定為「主元件（菱形圖示）」的那顆膠囊標籤，手動把它的圓角 `cornerRadius` 改成 `4`、換個底色，觀察另外兩個 `ref` 分身標籤是不是**同步一起改變外觀**！
