# 第三章 🎬：動畫與動態影片感 — GSAP / Anime.js / Lottie

> [!TIP]
> **線上 demo**：[開啟動畫分類](https://roberthsu2003.github.io/UI_UX_Prototype/frameworks.html#motion)

## 🧠 先懂三個動態設計概念

會用 After Effects 或 Premiere 的設計師其實已經懂這些概念，只是在網頁上換了名字：

| 概念 | 影片剪輯裡的說法 | 網頁動畫的說法 | Prompt 範例 |
| :--- | :--- | :--- | :--- |
| **時間軸** | 剪輯軌道上依序排列片段 | `timeline` | 「卡片先彈出，接著標題逐字出現，最後按鈕彈入」 |
| **緩動曲線** | 關鍵影格的速度曲線 | `easing`（ease-out、back、elastic） | 「用 back.out 讓按鈕有回彈感」 |
| **交錯延遲** | 多個圖層錯開幾格開始 | `stagger` | 「列表項目每個間隔 0.08 秒依序滑入」 |

> [!IMPORTANT]
> **CSS 動畫就夠了嗎？** 簡單的 hover、淡入，用 CSS `transition` 就夠了。需要**多段依序播放、可暫停倒轉、跟捲動同步、逐字拆解**時，才需要動畫框架。

---

## 1. GSAP — 專業網頁動畫的業界標準

* **一句話定位**：GreenSock Animation Platform，被大量得獎網站採用的動畫引擎。核心是「時間軸」：把多段動畫像剪輯影片一樣精準排列。現在已完全免費（包含原本的付費外掛）。
* **適合用在**：
  * 首頁進場動畫、新品發表頁
  * 逐字、逐行的文字動畫（搭配 SplitText）
  * 搭配 ScrollTrigger 做捲動動畫（見 [第四章](./04_資料視覺化與捲動互動.md)）
* **不適合**：只有按鈕 hover 這類簡單效果時，用 CSS 即可。
* **Demo**：[新品上市時間軸](https://roberthsu2003.github.io/UI_UX_Prototype/demos/motion-gsap.html)：一張宣傳卡片的元素依序登場，可以播放、倒轉，或拖曳進度條逐格檢查。
* **關鍵字**：`gsap.timeline`、`stagger`、`ease: back.out / elastic.out`、`SplitText`

```text
請用 GSAP 的 timeline 製作一張「新品上市」宣傳卡片的進場動畫：卡片彈出 → 背景色塊依序登場 →
標籤落下 → 標題逐字翻轉出現 → 副標滑入 → CTA 按鈕彈出。下方提供播放、倒轉、重播按鈕與可拖曳的進度條。
請輸出成單一 HTML 檔，GSAP 從 CDN 載入。
```

---

## 2. Anime.js — 輕巧好上手的交錯動畫

* **一句話定位**：輕量的動畫函式庫，語法直覺，特別擅長讓一群元素「依序、交錯」動起來，例如從點擊位置向外擴散的波紋。
* **適合用在**：
  * 格狀、卡片列表的交錯進場
  * SVG 線條描繪動畫（Logo 一筆一畫畫出來）
  * 輕量的微互動
* **不適合**：需要複雜時間軸與捲動整合時，GSAP 的生態更完整。
* **Demo**：[格狀波紋](https://roberthsu2003.github.io/UI_UX_Prototype/demos/motion-anime.html)：點任一個方塊，動畫會以那一格為中心向外擴散，有波紋、旋轉、變色三種模式。
* **關鍵字**：`anime.stagger`、`grid`、`from: center`、`SVG line drawing`

```text
請用 Anime.js 製作一個 14×9 的方塊格狀動畫：點擊任何一格，動畫會以該格為中心向外波紋擴散
（使用 anime.stagger 的 grid 與 from 參數），並提供「波紋 / 旋轉 / 變色」三種模式按鈕。請輸出成單一 HTML 檔。
```

## 3. Lottie — 把 After Effects 動畫搬上網頁

* **一句話定位**：設計師在 After Effects 做好動畫，用 **Bodymovin** 外掛匯出成 JSON 檔，Lottie 就能在網頁、App 上以**向量、不失真、檔案很小**的方式播放。
* **適合用在**：
  * Loading 動畫、空狀態插圖
  * 成功 / 失敗 / 打勾等回饋動畫
  * 品牌吉祥物、動態 Logo
* **不適合**：需要隨使用者操作即時變化的動畫（請改用 Rive 或 GSAP）。
* **Demo**：[Lottie 彈跳球](https://roberthsu2003.github.io/UI_UX_Prototype/demos/motion-lottie.html)：一顆帶有擠壓伸展與影子的彈跳球，可以暫停、調速度、逐格拖曳。
* **關鍵字**：`lottie-web`、`Bodymovin`、`LottieFiles`、`.json / .lottie`

```text
請用 lottie-web 在網頁上播放這個 Lottie JSON 動畫（附件），並加上播放 / 暫停按鈕、速度滑桿與逐格拖曳的進度條。
如果沒有附件，請先自行產生一個小球彈跳（含擠壓伸展與影子）的 Lottie JSON。
```

> [!TIP]
> **設計師與工程師的交接流程**：AE 製作 → Bodymovin 匯出 JSON → 上傳到 [LottieFiles](https://lottiefiles.com/) 預覽與分享 → 工程師用 lottie-web 載入。LottieFiles 上也有大量免費動畫，可以直接拿來放進原型。

## 🎞️ 延伸認識：更進階的「動態影片」工具

以下兩個工具較進階，本圖鑑不提供 demo，但值得知道它們的存在：

### Rive — 可以互動的動畫
* **定位**：類似 Lottie，但動畫內建「狀態機（State Machine）」，可以依據滑鼠、點擊、輸入值切換動畫狀態。例如角色的眼睛會跟著游標轉、按鈕按下時有不同表情。
* **適合**：互動吉祥物、遊戲化介面、會「回應」使用者的按鈕與圖示。
* **網站**：[rive.app](https://rive.app/)

### Remotion — 用程式碼「做影片」
* **定位**：用 React 寫元件，再**輸出成真正的 MP4 影片**。適合大量產生格式相同、內容不同的影片，例如每位會員專屬的年度回顧影片、每週數據報告影片、社群短影音模板。
* **注意**：需要 Node.js 與 React 開發環境，適合交由工程師實作。提案時可以說「用 Remotion 批次產生個人化影片」。
* **網站**：[remotion.dev](https://www.remotion.dev/)

## 🔍 怎麼選？

| 需求 | 首選 |
| :--- | :--- |
| 多段依序播放、需要精準控制的進場動畫 | **GSAP** |
| 輕量的交錯 / 波紋效果 | **Anime.js** |
| 設計師已經在 AE 做好的動畫 | **Lottie** |
| 會回應滑鼠與點擊的互動角色 | **Rive** |
| 要輸出成 MP4 影片檔 | **Remotion** |
| React 專案的介面轉場 | **Motion（原 Framer Motion）** |
