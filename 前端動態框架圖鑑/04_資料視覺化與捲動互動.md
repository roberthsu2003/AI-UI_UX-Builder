# 第四章 📊：資料視覺化與捲動互動 — D3.js / Chart.js / ScrollTrigger + Lenis

> [!TIP]
> **線上 demo**：[開啟資料視覺化與捲動互動分類](https://roberthsu2003.github.io/UI_UX_Prototype/frameworks.html#data)

## 🧠 先懂一個概念：標準圖表 vs. 客製化視覺化

| | 標準圖表 | 客製化視覺化 |
| :--- | :--- | :--- |
| **長相** | 長條圖、折線圖、圓餅圖 | 關係網路圖、樹狀圖、地圖、桑基圖、任何你想像的形式 |
| **製作速度** | 幾行設定就完成 | 需要較多程式碼 |
| **代表框架** | **Chart.js**、ECharts | **D3.js** |
| **常見場景** | 後台儀表板、成果報告 | 數據新聞、年報專題、資訊圖表 |

---

## 1. D3.js — 資料視覺化的瑞士刀

* **一句話定位**：把資料「綁定」到 SVG 圖形上，只要想得到的視覺形式都做得出來。《紐約時報》等媒體的數據新聞大量使用它。
* **適合用在**：
  * 網站架構圖（Sitemap）、組織圖、關係網路圖
  * 數據新聞、年報的客製化互動圖表
  * 地圖、樹狀圖、桑基圖、和弦圖
* **不適合**：只需要標準長條 / 折線圖時，用 Chart.js 快很多。
* **Demo**：[網站架構力導向圖](https://roberthsu2003.github.io/UI_UX_Prototype/demos/data-d3.html)：把一個咖啡品牌網站的 Sitemap 畫成可拖曳的力導向圖，滑鼠移到節點上會高亮它的上下層路徑，呼應 [網站架構觀念](../網站架構觀念/README.md) 與 [導覽列](../網站架構觀念/導覽列/README.md) 單元。
* **關鍵字**：`forceSimulation`、`d3.hierarchy`、`zoom`、`drag`、`SVG`

```text
請用 D3.js 的 forceSimulation 畫出一個咖啡品牌網站的 Sitemap 力導向圖：首頁為中心，往外是第一層與第二層頁面，
依層級使用不同顏色與大小；節點可以拖曳、畫面可以縮放，滑鼠移到節點時高亮它的上下層路徑。請輸出成單一 HTML 檔。
```

> [!TIP]
> **實用技巧**：把你的網站頁面清單（例如從 [如何評估現有的網站](../如何評估現有的網站/README.md) 單元整理出的結構）直接貼給 AI，請它用這個 Prompt 畫成互動 Sitemap，就是一份很有說服力的提案附件。

## 2. Chart.js — 最容易上手的圖表函式庫

* **一句話定位**：幾行設定就能做出漂亮、有動畫、可互動（滑鼠提示、點圖例隱藏數列）的標準圖表，而且自動支援 RWD。
* **適合用在**：
  * 後台儀表板、KPI 報表
  * 活動成果頁的統計圖
  * 在原型裡快速放入「看起來真實」的圖表，讓提案更有說服力
* **不適合**：需要非常特殊的視覺形式時，請改用 D3.js。
* **Demo**：[流量儀表板](https://roberthsu2003.github.io/UI_UX_Prototype/demos/data-chartjs.html)：兩年度流量比較的折線圖加上流量來源甜甜圈圖，可以隨機更新資料、切換長條或折線。
* **關鍵字**：`line / bar / doughnut`、`tooltip`、`responsive`、`tension 平滑曲線`

```text
請用 Chart.js 製作一個網站流量儀表板：左邊是 12 個月的流量比較折線圖（兩年度、平滑曲線、半透明填色），
右邊是流量來源甜甜圈圖；提供「隨機更新資料」與「切換長條 / 折線」按鈕，並支援 RWD。請輸出成單一 HTML 檔。
```

> [!NOTE]
> **其他選擇**：`Apache ECharts`（圖表種類最豐富，中文文件完整）、`Recharts`（React 專案常用）。

## 3. GSAP ScrollTrigger + Lenis — 捲動即敘事

* **一句話定位**：**ScrollTrigger** 把動畫的進度綁在捲軸位置上，決定「捲到哪裡、播放什麼」；**Lenis** 讓捲動變得平滑，負責「捲動的手感」。兩者搭配，就是許多品牌官網「一鏡到底」的做法。
* **適合用在**：
  * 品牌故事頁、產品發表頁、年度回顧
  * 畫面釘選（pin）後，垂直捲動轉為水平移動
  * 捲動時逐字點亮、數字跳動、視差（Parallax）
* **不適合**：資訊型、需要快速找資料的頁面（例如 FAQ、商品列表）不要過度使用，以免使用者找不到內容。
* **Demo**：[捲動敘事單頁](https://roberthsu2003.github.io/UI_UX_Prototype/demos/scroll-gsap.html)：包含閱讀進度條、光球放大、逐字點亮、釘選後水平捲動、數字跳動。
* **關鍵字**：`ScrollTrigger`、`scrub`、`pin`、`horizontal scroll`、`Lenis smooth scroll`、`parallax`

```text
請用 GSAP ScrollTrigger 搭配 Lenis 平滑捲動，製作一個品牌故事單頁：頂部有閱讀進度條；
第一屏光球隨捲動放大、標題淡出；第二屏文字隨捲動逐字點亮；第三屏釘選畫面並轉為水平捲動 4 張卡片；
第四屏數字隨捲動跳到 128,000+。請支援 prefers-reduced-motion，輸出成單一 HTML 檔。
```

### 常見捲動手法速查表

| 手法 | 效果 | 對 AI 說 |
| :--- | :--- | :--- |
| **Scrub** | 動畫進度跟著捲軸走，往回捲就倒轉 | `scrub: true` |
| **Pin** | 某個區塊固定在畫面上，直到動畫播完 | `pin: true` |
| **水平捲動** | 往下捲，內容卻往左移動 | `pin + 水平位移 x` |
| **視差 Parallax** | 前景與背景以不同速度移動，產生深度感 | `parallax layers` |
| **逐字點亮** | 文字隨捲動一個字一個字變亮 | `split text + scrub` |

> [!WARNING]
> 捲動動畫屬於「高衝擊」效果。提案時記得考慮：**手機上的效能**、**對動態敏感的使用者**（`prefers-reduced-motion` 時直接顯示最終畫面），以及**內容仍然要能被搜尋引擎讀到**（文字用 HTML，不要做成圖片）。
