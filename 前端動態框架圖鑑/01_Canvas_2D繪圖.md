# 第一章 🖌️：Canvas 2D 繪圖 — p5.js / PixiJS / Fabric.js

> [!TIP]
> **線上 demo**：[開啟 Canvas 2D 分類](https://roberthsu2003.github.io/UI_UX_Prototype/frameworks.html#canvas)

## 🧠 先懂一個概念：DOM 與 Canvas 的差別

| | 一般網頁元素（DOM：HTML + CSS） | Canvas 畫布 |
| :--- | :--- | :--- |
| **比喻** | 用積木（按鈕、文字、圖片）排出頁面 | 一張白紙，用程式「畫」出每一格畫面 |
| **擅長** | 文字內容、表單、可被搜尋引擎讀取 | 成千上萬個圖形、粒子、像素級特效 |
| **不擅長** | 同時有上千個元素在動時會卡頓 | 文字無法被選取與搜尋、無障礙需另外處理 |

> [!NOTE]
> 簡單判斷：**畫面上「會動的東西」超過幾十個，或需要手繪 / 像素級的效果時，就該考慮 Canvas。** 內容型的文字與按鈕仍應保留用 HTML 製作。

## 1. p5.js — 為設計師與藝術家打造的創意程式工具

* **一句話定位**：用很少的程式碼畫出生成藝術（Generative Art），源自 MIT 媒體實驗室的 Processing 計畫，設計學院常拿來教「創意程式」。
* **適合用在**：
  * 品牌主視覺的生成式圖紋（每次載入都長得不一樣）
  * 展覽、活動的互動海報與裝置藝術
  * 跟著滑鼠移動的筆刷、粒子、線條效果
* **不適合**：需要上萬個物件同時流暢運作的場景（請改用 PixiJS）。
* **Demo**：[流場生成藝術](https://roberthsu2003.github.io/UI_UX_Prototype/demos/canvas-p5.html)：上千條細線沿著「雜訊流場」流動，滑鼠附近會產生漩渦，點擊可以換配色。
* **關鍵字**：`Perlin noise`、`flow field`、`generative art`、`拖尾效果`

```text
請用 p5.js 製作一個全螢幕的生成藝術背景：上千條細線沿著 Perlin noise 流場流動並留下拖尾，
滑鼠附近會產生漩渦，點擊畫面可切換 4 組配色。請輸出成單一 HTML 檔，p5.js 從 CDN 載入。
```

## 2. PixiJS — GPU 加速的高效能 2D 引擎

* **一句話定位**：用顯示卡（WebGL）繪製 2D 圖形，一次畫上萬個物件仍然維持 60fps。很多網頁小遊戲與互動廣告都是用它做的。
* **適合用在**：
  * 大量粒子、彩帶、雪花、星空等氛圍效果
  * 2D 網頁小遊戲（抽獎轉盤、接金幣、刮刮樂）
  * 互動式插畫、角色動畫（可搭配 Spine 骨架動畫）
* **不適合**：只有幾個簡單圖形時，用 CSS 或 SVG 就夠了，不需要載入整個引擎。
* **Demo**：[3000 顆粒子](https://roberthsu2003.github.io/UI_UX_Prototype/demos/canvas-pixi.html)：滑鼠靠近會推開粒子，點擊會爆炸擴散，還可以一直往上加數量，同時觀察 FPS（每秒畫面數）。
* **關鍵字**：`ParticleContainer`、`Sprite`、`高效能`、`60fps`

```text
請用 PixiJS 製作一個全螢幕粒子場景：3000 顆發光圓點在畫面中漂浮，滑鼠靠近時粒子被推開，
點擊時產生爆炸擴散，右下角顯示 FPS。請輸出成單一 HTML 檔，PixiJS 從 CDN 載入。
```

## 3. Fabric.js — 讓畫布上的圖形「可以被編輯」

* **一句話定位**：讓 Canvas 上的每個圖形都能被選取、拖曳、縮放、旋轉，像在網頁上嵌入一個迷你 Canva。
* **適合用在**：
  * 線上客製化商品設計器（T 恤、名片、貼紙、喜帖）
  * 白板、截圖標註工具
  * 活動海報 / 社群圖卡產生器（最後可匯出 PNG）
* **不適合**：純展示、不需要讓使用者編輯的動畫。
* **Demo**：[海報編輯器](https://roberthsu2003.github.io/UI_UX_Prototype/demos/canvas-fabric.html)：拖曳、縮放、旋轉圖形，雙擊文字可以編輯，還能新增圖形與匯出 PNG。
* **關鍵字**：`可編輯畫布`、`物件選取控制點`、`IText`、`toDataURL 匯出`

```text
請用 Fabric.js 製作一個「活動海報編輯器」：畫布上預設放入標題文字、圓形、圓角方塊，
使用者可以拖曳、縮放、旋轉並雙擊編輯文字；工具列提供新增方塊、新增圓形、新增文字、刪除與匯出 PNG。
請輸出成單一 HTML 檔。
```

## 🔍 三者怎麼選？

| 需求 | 首選 |
| :--- | :--- |
| 我要「有藝術感」的生成圖像、快速實驗 | **p5.js** |
| 我要「很多東西同時動」而且不能卡 | **PixiJS** |
| 我要「讓使用者自己動手編輯」 | **Fabric.js**（也可考慮 Konva.js） |

> [!NOTE]
> **其他值得認識的 2D 框架**：`Konva.js`（與 Fabric 類似，React 整合佳）、`Paper.js`（向量路徑運算）、`Matter.js`（2D 物理引擎，做掉落、碰撞效果）。
